## 1. โปรเจกต์นี้คืออะไร

**ชุบชีวิตเกม Durango: Wild Lands (NEXON)** ที่ปิดเซิร์ฟไปแล้ว ด้วยการเขียน **private server ขึ้นมาใหม่ทั้งหมด**
- ตัวเกมฝั่ง client (Unity 2017.4.34f1) เป็นของเดิมที่ decompile ด้วย ILSpy
- server เราเขียนเองด้วย **C# / .NET 9** พูดโปรโตคอลเดิมของเกม (header 24 ไบต์ + MsgPack → Snappy)
- โฟกัสตอนนี้: เตรียมเปิด **Beta 1.0 (เกาะเริ่มต้น เลเวล 1-10)**

**ตำแหน่งโปรเจกต์:** `C:\Users\thana\Desktop\Durango Claude\`

## 2. สถานะตอนนี้ (ล่าสุด: 15 ส.ค. 2026 — รอบ 4)

**✅ พร้อมเปิด Beta 1.0 เกือบสมบูรณ์** — เหลือเกณฑ์สุดท้าย: เล่นด้วยตัวเกมจริง 30 นาทีเป็นรอบสุดท้าย

### เล่นได้แล้ว
- เข้าเซิร์ฟพร้อมกันหลายคน เห็นตัวละครซิงก์ตรงกัน
- เก็บของธรรมชาติ · คราฟต์ · สร้าง/ทุบสิ่งปลูกสร้าง · เรียนสกิล · ใส่อุปกรณ์ (คนอื่นเห็นด้วย)
- **ระบบเซฟ** — ของ/สกิล/บ้าน/ตำแหน่ง ไม่หาย (autosave 60 วิ)
- **สัตว์ป่า 34 ตัว 10 ชนิด** (SpawnTable) — เดิน ไล่ หนี สู้ ตาย + **ซากแล่เนื้อได้** (ButcheryData)
- ตาย-ฟื้น · ค่าหิว/ล้า/สตามินา (Gauge แบบ keyframe) · กล่องเก็บของ 200 ช่อง
- แชท + อิโมติคอน (ช่องรวม)

### แก้รอบล่าสุด (15 ส.ค. รอบ 4)
- คลิกสัตว์แล้วปุ่มโจมตีไม่เด้ง → แก้แล้ว (เพิ่ม HandleTouchAnimal)
- สัตว์สวนกลับไวขึ้น (0.5 วิ) + คูลดาวน์จริงของแต่ละชนิด (1.3–3.0 วิ)
- ระบบแล่เนื้อ (ซาก 150 วิ · เรืองแสงให้คนที่ฆ่า)
- แก้บั๊กเปิดเซิร์ฟซ้ำ 2 ตัวทำงานพร้อมกันทับไฟล์เซฟ (ExclusiveAddressUse)

### กันโกง 42/42 test ผ่าน
- token/session auth (GP-12) · ระยะเอื้อมจริง (GP-09) · เพดานความเร็ว 900 u/s (M-2)
- ของก๊อปไม่ได้ (GP-03/H-8) · เปิดกล่อง/ทุบบ้านคนอื่นไม่ได้ (M-4) · rate limit 120/s (M-6)
- whitelist + จอง IP (H-1) · กัน DoS (H-3) · cheat ปิดเป็นค่าเริ่มต้น (H-2)

## 3. สิ่งที่ยังไม่ทำ / ค้างอยู่

| เรื่อง | รายละเอียด |
|---|---|
| **เทสรอบสุดท้าย** | เล่นด้วยตัวเกมจริง 30 นาที (เกณฑ์ข้อ 3 ของ Beta 1.0) — ก่อนเปิด |
| เพ็ท · ปาร์ตี้ · แคลน · ตลาด · ภารกิจ | เมนูซ่อนไว้หมดแล้ว (24 เมนู) |
| แชทส่วนตัว | ต้องทำ auth ให้ radiotower ก่อน (พอร์ต 8192 ปิดอยู่) |
| คราฟต์เช็ค tag วัตถุดิบ | ต้องให้ไอเทมมี Tags ก่อน (GP-08b) |
| หน่วงเก็บของธรรมชาติ | ยัง 2.1 วิตายตัว (GP-09b) |
| แล่เนื้อ | ยังไม่ต้องใช้มีด / ไม่มีสกิล butchery |

## 4. วิธีเปิดใช้งาน (ข้อมูลให้ agent รู้ พอช่วยเหลือได้)

- **เปิดเซิร์ฟ:** `cd "C:\Users\thana\Desktop\Durango Claude\server" && dotnet run -- --whitelist data/whitelist.txt`
- **เปิดเกม+ต่ออัตโนมัติ:** `powershell -File "C:\Users\thana\Desktop\Durango Claude\tools\connect-game.ps1"`
- **เทส auto:** `cd test-client && dotnet run -- --gp-check` (42 ข้อ) · `--multi-check` (9 ข้อ)
- **พอร์ต:** gateway HTTP 8190 · game TCP 8191 · radiotower 8192 (ปิด)
- ⚠️ ห้ามเปิดเกม/เซิร์ฟซ้อน 2 ตัว — มีการ์ดกันไว้แล้ว แต่ควรเช็ค
- ⚠️ ต้อง kill DurangoServer/dotnet ก่อน build (ไฟล์ล็อก)
