# ตั้งค่าเซิร์ฟ + ข้อมูลถูกเก็บที่ไหน

**ไฟล์:** `ServerCore/ServerConfig.cs` · ค่าจริงอยู่ที่ `server/data/config.json`
**ตัวแก้:** `เทสเกม.bat` → ข้อ **17** (หรือแก้ไฟล์ตรง ๆ ด้วย Notepad ก็ได้)

---

## 1. `data/config.json` — ค่าปรับสมดุลทั้งหมด

เดิมเรทเกิดสัตว์/เลือด/ดาเมจ/exp เป็น `const` ในโค้ด → แก้ทีต้อง build ใหม่ทุกที
คนที่ดูแลเซิร์ฟแต่ไม่ได้เขียนโค้ดจึงปรับอะไรเองไม่ได้เลย ตอนนี้ย้ายมาไว้ในไฟล์ JSON ไฟล์เดียว

```
เปิดเซิร์ฟ → ไม่มีไฟล์ = สร้างให้เองพร้อมค่าเริ่มต้น
ระหว่างรัน → ตรวจเวลาแก้ไขไฟล์ทุก 5 วินาที เปลี่ยนแล้วโหลดใหม่ทันที
ไฟล์เสีย   → เตือนใน log แล้วใช้ค่าเดิมต่อ (เซิร์ฟไม่ล่ม)
```

| กลุ่ม | มีผลเมื่อไร |
|---|---|
| `animals` (เลือด/ดาเมจ/ความเร็ว/เวลาซาก/เวลาเกิดใหม่) | **ทันที** |
| `exp` (แต้มต่อการกระทำ · แต้มสกิลต่อเลเวล) | **ทันที** |
| `spawn` (ชนิด/โควตา/เลเวล/นิสัย) | **ตอนเปิดเซิร์ฟใหม่** — สัตว์ถูกเกิดไปแล้วตั้งแต่ตอนเปิด<br>ยกเว้นเลเวล/นิสัย/คูลดาวน์ ที่ตัวเกิดใหม่จะใช้ค่าใหม่ทันที |

### `animals`

| ค่า | ค่าเริ่มต้น | ทำอะไร |
|---|---:|---|
| `LifeBase` / `LifePerLevel` | 30 / 8 | เลือดสัตว์ = `LifeBase + เลเวล × LifePerLevel` |
| `DamageBase` / `DamagePerLevel` | 2 / 0.4 | ดาเมจต่อครั้ง |
| `CorpseSeconds` | 150 | ซากอยู่ในโลกกี่วินาที (ต้องนานพอให้แล่จนครบ) |
| `RespawnSeconds` | 60 | ตายแล้วกี่วินาทีเกิดตัวใหม่ |
| `ChaseSpeed` / `FleeSpeed` | 300 / 280 | หน่วยโลกต่อวินาที (1 tile = 200) |
| `SightTiles` | 6 | ตัวนิสัยดุเห็นคนในระยะกี่ tile แล้วเริ่มไล่ |
| `GiveUpTiles` | 20 | ไล่เกินกี่ tile แล้วเลิกสนใจ |
| `AggroSeconds` | 20 | โกรธนานกี่วินาที |
| `FirstAttackDelay` | 0.5 | โดนตีแล้วกี่วินาทีถึงสวนกลับครั้งแรก |
| `SpawnRadiusTiles` | 30 | กระจายจุดเกิดรอบจุดเข้าเกมกี่ tile |
| `WanderRadiusTiles` | 12.5 | เดินออกจากบ้านตัวเองได้ไกลกี่ tile |
| `MinTilesInland` | 4 | สัตว์ **ตัวเล็กสุด** ต้องเกิดลึกจากชายฝั่งกี่ tile (0 = เกิดริมหาดได้) |
| `InlandTilesPerSize` | 3 | ตัวใหญ่ต้องลึกเพิ่มอีกกี่ tile ต่อ 1 ระดับขนาด |

**`MinTilesInland` + `InlandTilesPerSize` = กติกา "ตัวใหญ่อยู่กลางเกาะ"**
ระยะที่ต้องลึก = `MinTilesInland + (size_level − 1) × InlandTilesPerSize`
ค่าเริ่มต้นให้ ขนาด 1 → 4 tile · ขนาด 2 → 7 · ขนาด 4 (สเตโก/ทริเซรา) → 13 · ขนาด 7 (ไทแรนโนฯ) → 22
รายละเอียดเรื่องขนาดตัวและการอ่านไบโอมอยู่ที่ [Biomes.md](Biomes.md)

### `exp`

| ค่า | เริ่มต้น | ได้ตอนไหน |
|---|---:|---|
| `KillBase` + `KillPerLevel` | 4 + 3/เลเวล | ฆ่าสัตว์ (lv3 = 4+9 = 13 exp) |
| `Gather` | 2 | เก็บของธรรมชาติ 1 ชิ้น |
| `Butchery` | 3 | แล่ซาก 1 ชิ้นส่วน |
| `Craft` | 5 | คราฟต์สำเร็จ |
| `Build` | 8 | สร้างเสร็จ 1 หลัง |
| `SkillPointsPerLevel` | 3 | ขึ้นเลเวลแล้วได้แต้มสกิลกี่แต้ม |

> ตารางเลเวล (`LevelData.cs`) เป็น **ค่าจริงของเกม** — lv2 ที่ 11 exp · lv3 ที่ 25 · lv11 ที่ 733
> client ใช้ตารางชุดเดียวกันวาดหลอด exp จึงห้ามแก้ ถ้าอยากให้เลเวลขึ้นเร็ว/ช้า ให้ปรับ `exp` แทน

### `skills` — ผลของสกิล

รวมเลเวลสกิล**ทุกอันในหมวดเดียวกัน** เทียบกับ `FullAt` (เริ่มต้น 60) ได้สัดส่วน 0-1
แล้วคูณกับเพดานของหมวดนั้น เช่น สกิลหมวดเก็บของรวม 30 เลเวล = ครึ่งทาง ⇒ เก็บของเร็วขึ้น 20%

| ค่า | เริ่มต้น | ผลเมื่อสกิลเต็ม |
|---|---:|---|
| `FullAt` | 60 | รวมเลเวลในหมวดถึงเท่านี้ = โบนัสเต็ม |
| `GatherSpeed` / `GatherBonus` | 0.4 / 0.3 | เก็บของเร็วขึ้น 40% · 30% ที่จะได้ของเพิ่มอีกชิ้น |
| `ButcherySpeed` / `ButcheryBonus` | 0.4 / 0.3 | แล่ซากเร็วขึ้น 40% · 30% ที่จะได้ชิ้นส่วนเพิ่ม |
| `MeleeDamage` | 0.5 | ดาเมจที่ตีออก +50% |
| `DefenseReduce` | 0.3 | ดาเมจที่รับ -30% |
| `CraftSpeed` | 0.4 | คราฟต์เร็วขึ้น 40% (ใช้หมวดคราฟต์ที่เก่งที่สุด) |
| `StaminaSave` | 0.3 | ทุกอย่างเปลืองสตามินาน้อยลง 30% |
| `RequiredPlayerLevelPerSkillLevel` | 1.0 | สกิลเลเวล N ต้องมีเลเวลผู้เล่น N × ค่านี้ |

**ราคาแต้มสกิล:** เรียนสกิลเลเวล N ใช้ N แต้ม (อัปจาก 2 เป็น 5 = จ่าย 3) · ลืมสกิลคืนแต้มเท่าที่จ่าย
แต้มได้จากการขึ้นเลเวลเท่านั้น (`exp.SkillPointsPerLevel` เริ่มต้น 3 แต้ม/เลเวล)

ดูโบนัสของตัวเองระหว่างเทส: `cheat skills` ในบอทคอนโซล

### `spawn` — รายชนิด

```json
{ "Type": 2042, "Name": "กิ้งก่า", "MinLevel": 1, "MaxLevel": 3,
  "Quota": 6, "Behavior": "Flee", "MinTilesFromEntry": 0, "AttackCooltime": 1.4 }
```

- `Quota` = ให้มีในโลกพร้อมกันกี่ตัว (**0 = ไม่ต้องเกิดเลย** ใช้ปิดสัตว์บางชนิดได้)
- `Behavior` = `Flee` หนีอย่างเดียว · `FightBack` สู้กลับเมื่อโดนตี · `Aggressive` ไล่กัดก่อน
- `MinTilesFromEntry` = เขตปลอดภัย ตัวดุต้องเกิดไกลจากจุดเข้าเกมอย่างน้อยเท่านี้
- `AttackCooltime` = ค่า `attack_cooltime` **จริงจากข้อมูลเกม** เว้นระยะระหว่างการกัด

### `world` — การส่งข้อมูลแมพให้ client

| ค่า | เริ่มต้น | ทำอะไร |
|---|---:|---|
| `ChunkSendRange` | 2 | ส่ง garden (ต้นไม้/หิน) รอบตัวผู้เล่นกี่ chunk · 2 = 5×5 · 1 chunk = 16 tile |

⚠️ **ต้องเท่ากับ `_visibleRange` ของ client** (`client/Durango.Terrain/TerrainBase.cs` → `InitChunkPool`)

- ตั้ง**น้อยกว่า** client: chunk วงนอกได้ภูมิประเทศแต่ไม่มีต้นไม้ พอเดินเข้าใกล้ server ค่อยส่งตามมา
  → client สร้าง chunk ใหม่ทั้งก้อน = **เห็นแมพรีเฟรชกลางทาง**
- ตั้ง**มากกว่า** client: client ทิ้ง chunk ที่เกินระยะทันที แต่ server จำว่าส่งไปแล้ว → **ต้นไม้หายถาวร**

### ค่าที่ยังไม่ได้ย้ายมา (ต้องแก้ในโค้ด/บรรทัดคำสั่ง)

เพดาน connection · rate limit · ขนาดกระเป๋า/กล่อง · จำนวนบ้านต่อคน · เลือด/สตามินาผู้เล่น ·
เวลา autosave — พวกนี้เป็นเรื่องความปลอดภัย/ความเสถียร ไม่ใช่การปรับสมดุล จึงยังคุมด้วย
`--max-connections` ฯลฯ ตอนเปิดเซิร์ฟ (ดู `docs/operations/BETA-OPS.md`)

### ตรวจว่าค่าที่ใส่ไม่พังเกม

`ConfigRoot.Validate()` ปฏิเสธไฟล์ทั้งไฟล์ (แล้วใช้ค่าเดิมต่อ) ถ้า:
เลือด/เวลา/ความเร็ว ≤ 0 · ชนิดสัตว์นอกช่วง 2000-2999 · ช่วงเลเวลกลับหัว ·
โควตารายชนิดเกิน 200 · สัตว์รวมทั้งเกาะเกิน 500 ตัว

## 2. ข้อมูลผู้เล่นเก็บยังไง

**ไม่มี database engine** — เป็น **ไฟล์ JSON ธรรมดา** ทั้งหมด อยู่ใน `server/saves/`

```
server/saves/
├── world.json              โลกทั้งใบ: สิ่งปลูกสร้าง · ของในกล่อง · ของธรรมชาติที่ถูกเก็บไปแล้ว
├── players/<id>.json        1 ไฟล์ต่อ 1 ตัวละคร
└── accounts/<id>.json       1 ไฟล์ต่อ 1 บัญชี (ผูก entity id กับ IP แรกที่จอง)
```

### `players/<entityId>.json` มีอะไรบ้าง

| ฟิลด์ | คือ |
|---|---|
| `EntityId` `Name` `EntityType` | ตัวตนของตัวละคร |
| `Level` `TotalExp` `SkillPoints` | ความคืบหน้า — **`TotalExp` เป็นตัวจริง เลเวลคิดใหม่จาก exp ตอนโหลด** |
| `PosX` `PosY` `Yaw` `HasPosition` | ยืนอยู่ตรงไหนตอนออกเกม |
| `DisplayJson` | หน้าตา/เพศ (เก็บดิบไว้ทั้งก้อน) |
| `Inventory[]` | ของในกระเป๋าทุกชิ้น (id · prototype · ชื่อ · ไอคอน · เลเวล · ความทนทาน) |
| `EquippedItems{}` | ช่อง → item id ที่ใส่อยู่ |
| `KnownSkills[]` | สกิลที่เรียนแล้วและเลเวลของแต่ละอัน |
| `Survival` | เลือด/สตามินา/ความล้า ตอนออกเกม |
| `StarterGiven` | ได้ของแถมตอนเข้าเกมครั้งแรกไปแล้วหรือยัง |

**จังหวะเขียนไฟล์:** autosave ทุก 60 วินาที (เฉพาะคนที่มีอะไรเปลี่ยน — ดูธง `MarkDirty`) ·
ตอนผู้เล่นออกจากเกม · ตอนกด Ctrl+C ปิดเซิร์ฟ

**ทำไมเป็น JSON ไม่ใช่ SQLite/MySQL:** ผู้เล่นระดับ 32 คน เขียนทีละไฟล์เล็ก ๆ ทุก 60 วินาที
ยังห่างจากจุดที่ไฟล์จะเป็นคอขวดมาก และ **เปิดอ่าน/แก้ด้วยมือได้ทันที** ซึ่งมีค่ามากตอนดีบั๊ก
ถ้าวันหนึ่งคนเยอะจนช้า ค่อยเปลี่ยนตัวเก็บข้างใน `SaveStore` ที่เดียว — โครงข้างนอกไม่ต้องแก้

**สำรอง/กู้คืน:** ทำตาม [`S0-FOUNDATION.md`](S0-FOUNDATION.md#backup-and-restore-procedure): หยุด server แบบ graceful, snapshot ทั้ง configured save root และ restore เข้าไดเรกทอรีแยกเพื่อยืนยันก่อน. `เทสเกม.bat` ข้อ 12 เป็น helper สำหรับ local snapshot เท่านั้นและต้องใช้ตอน server หยุดอยู่.

**แก้ข้อมูลผู้เล่นด้วยมือ:** ปิดเซิร์ฟก่อน แล้วแก้ไฟล์ JSON ตรง ๆ ได้เลย (แก้ระหว่างเซิร์ฟรัน
จะโดน autosave ทับ) — เช่นแก้ `TotalExp` เพื่อเซ็ตเลเวล หรือเติมของใน `Inventory`
