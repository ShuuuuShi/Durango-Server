# ค่าพลังสัตว์รายชนิด — เลือด · โจมตี · ป้องกัน

เอกสารนี้ตอบคำถาม **"ทำไมสัตว์ทุกตัวเคยแข็งเท่ากัน และตอนนี้คิดยังไง"**

---

## 1. ปัญหาเดิม — สูตรเดียวใช้กับ 213 ชนิด

เซิร์ฟคิดเลือดกับดาเมจสัตว์จากสูตรกลางใน `data/config.json` → `Animals`:

```
เลือด  = LifeBase   + level × LifePerLevel
ดาเมจ  = DamageBase + level × DamagePerLevel
```

สูตรนี้ไม่รู้จัก "ชนิด" เลย — กิ้งก่า lv3 กับบราคิโอ lv3 **เลือดเท่ากันเป๊ะ ดาเมจเท่ากันเป๊ะ**
ต่างกันแค่โมเดลกับขนาดตัว ทั้งที่แกนของเกมล่าสัตว์คือ "ตัวใหญ่ล้มยาก ตัวเล็กล้มง่าย"

---

## 2. ข้อมูลเกมจริงมีสูตรรายชนิดอยู่แล้ว

`data/assets/entity_types/animal.json` เก็บสูตรต่อชนิดเป็นข้อความ (ทั้ง 214 ชนิด ตรวจแล้วมีแค่ 3 รูปแบบ):

```
life_max = A × ((combat_level + B) ** C) × unstable_factor
attack   = (B + combat_level × C) × unstable_factor
defense  = (B + combat_level × C) × unstable_factor
```

นับแล้ว **สูตรเลือดต่างกัน 96 แบบ · ดาเมจ 86 แบบ** จาก 214 ชนิด — ไม่ใช่ค่าเดียวกันหมด

ตัวอย่างค่าจริง (ทุกตัว B = 24, C = 2, defense = 0 + 5×lv):

| ชนิด | id | เลือด (A) | โจมตี |
|---|---:|---:|---|
| กิ้งก่า | 2042 | 0.283 | 8.51 + 0.35×lv |
| แร็ปเตอร์ | 2001 | 0.422 | 15.39 + 0.64×lv |
| สเตโกซอรัส | 2000 | 1.389 | 25.13 + 1.05×lv |
| ไทรเซอราท็อปส์ | 2003 | 2.392 | 53.55 + 2.23×lv |

> **ต่างจากเรื่องสกิล** — ของสกิลมีแค่ชื่อ modifier ไม่มีตัวเลข (ค่าจริงอยู่ฝั่งเซิร์ฟ NEXON)
> แต่ของสัตว์**ตัวเลขมาครบ อยู่ในเครื่องแล้ว** เข้าข่าย "มีของจริงอยู่แล้วแต่ไม่ได้เสียบใช้"

### ความหมายตัวแปร (ยืนยันจากซอร์ส client ไม่ได้เดา)

- **`combat_level`** = เลเวลของสัตว์ ช่วง 1-80 ตรงกับ `combat_level_ranges` ในไฟล์เดียวกัน
- **`unstable_factor`** = ระดับความปั่นป่วนของเกาะ 1-8 (ดู `mission_exp_reward_ratio_by_unstable_factor` ใน `constants.json`
  และ `client/ArchipelagoRouteExtension.cs`) — เกาะเราไม่มีระบบนี้ จึงใช้ **1** (ค่าฐาน) ทำให้ทุกสูตรลดรูปเหลือค่าคงที่
  สกัดออกมาได้ตรง ๆ ไม่ต้องมี expression evaluator

### สิ่งที่กู้ไม่ได้จริง ๆ

`exp_amount` เป็น **0 ทั้ง 214 ชนิด** — ของจริงคิด exp จากระบบ ability/resistance ฝั่งเซิร์ฟ NEXON
ซึ่งไม่ได้ติดมากับ client · exp ที่ให้ต่อการฆ่าจึงยังเป็นค่าของเราเอง (ดู `ServerPlayer.Progress.cs`)

## 3. วิธีที่เซิร์ฟใช้ — อัตราส่วน ไม่ใช่ตัวเลขดิบ

> ⚠️ **ห้ามเอาตัวเลขดิบมาใช้ตรง ๆ** — เลือดแร็ปเตอร์ lv1 ตามเกม = 0.422 × 25² = **264**
> ขณะที่ config ปัจจุบันให้ **38** ต่างกัน 7 เท่า ถ้าสลับดื้อ ๆ จะกลับไปเป็นอาการ "ตี 25 ครั้ง (62 วิ)
> แล้วโดนสวน 216 หน่วย" ที่ `SpawnTable.cs` เคยเตือนไว้

จึงใช้ข้อมูลเกมเป็น **อัตราส่วนเทียบกับสัตว์อ้างอิง** (แร็ปเตอร์ 2001) แล้วคูณสูตรกลางเดิม:

```
เลือด  = config_life(level)   × species_life(level)   / reference_life(level)
ดาเมจ  = config_damage(level) × species_attack(level) / reference_attack(level)
```

ผล: **สมดุลที่จูนไว้แล้วคงอยู่** (แร็ปเตอร์ได้เท่าเดิมเป๊ะ) แต่แต่ละชนิดมีบุคลิกต่างกันจริง

| ชนิด | อัตราส่วนเลือด (lv1) |
|---|---:|
| กิ้งก่า | ×0.67 |
| แร็ปเตอร์ (อ้างอิง) | ×1.00 |
| ไทแรนโน | ×1.78 |
| สเตโกซอรัส | ×3.3 |
| ไทรเซอราท็อปส์ | ×5.7 |

ชนิดที่ไม่มีในตาราง (ไม่น่ามี — สกัดได้ครบ 214) จะถอยไปใช้สูตรกลางเดิม

### ปุ่มปรับใน `data/config.json` → `Animals`

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `SpeciesStats` | `true` | เปิดใช้อัตราส่วนรายชนิด · `false` = กลับไปสูตรกลางเหมือนเดิมทุกตัว |
| `SpeciesReference` | `2001` | entity type ของสัตว์อ้างอิง (ตัวที่ได้ ×1.00) |

## 4. สกัดใหม่ / ตรวจความครบ

ตารางอยู่ที่ `server/ServerCore/AnimalStatData.cs` — **สร้างด้วยสคริปต์ อย่าแก้มือ**

```
python server/scripts/extract_animal_stats.py \
    server/data/assets/entity_types/animal.json \
    server/ServerCore/AnimalStatData.cs
```

รอบล่าสุด: สกัดได้ **214 ชนิด · ข้าม 0** (สคริปต์จะพิมพ์รายการที่ข้ามถ้ามีสูตรรูปแบบใหม่โผล่มา)

ตรวจว่าตาราง C# ยังตรงกับข้อมูลเกม:

```
dotnet run --project server/DurangoServer.csproj -- --data-check
```

## 5. ค่าใน `animal.json` ที่ยังไม่ได้ใช้ (เผื่ออนาคต)

ข้อมูลเกมมี 40+ ฟิลด์ต่อชนิด ตอนนี้ใช้แค่เลือด/โจมตี/ป้องกัน ที่เหลือยังนอนอยู่:

`critical` · `accuracy` · `dodge` · `attack_rating` · `knock_back_resistance` · `blow_resistance`
· `damage_ratio_table` · `groggy_*` · `part_probability` · `preferred_food_tag` · `drop_item` · `taming_result`

> หมายเหตุ: `accuracy` / `dodge` / `attack_rating` จะมีผลก็ต่อเมื่อเซิร์ฟมีระบบ "ตีพลาด"
> ซึ่งตอนนี้ไม่มี (ทุกการโจมตีเป็น `DamageResult.Hit`) — เป็นงานออกแบบ ไม่ใช่งานเสียบข้อมูล
