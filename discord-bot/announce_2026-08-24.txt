🛠️ Durango Private Server — อัปเดต 24 ส.ค.

**วันนี้เพิ่มเครื่องมือทีมพัฒนา + แก้บั๊กเกมเพลย์หลายจุด**

🎮 **UI มือถือใช้งานเต็มรูปแบบแล้ว** — เจอว่าโค้ดเราเองไปจัดตำแหน่งทับ prefab มือถือของแท้จนดูเหมือน UI PC แก้แล้ว ได้หน้าคราฟต์ 3 คอลัมน์จริงจาก NEXON

🌀 **แก้ "กดวาปหลุมไม่ได้"** — เจอ 3 จุดขาดพร้อมกัน แก้ครบ เทสจริง: แตะหลุมวาร์ป → กดวาป → เลือกหลุมได้เลย

📍 **กฎวาง POI ใหม่** — ท่าเรือติดแม่น้ำเท่านั้น หลุมวาร์ป/รอยแยกอยู่ลึกในเกาะแล้ว ไม่ริมฝั่งอีก

🧩 **ระบบ mod แบบ Minecraft ใช้งานจริงแล้ว (ฝั่งเซิร์ฟ)** — โหลด .dll จาก mods/ ได้จริง แยกเฟส PreLoad/Load/PostLoad แบบ Forge มี Mod Loader tab ใน admin panel

🖥️ **Durango Server Controller — .exe คุมเซิร์ฟตัวจริง** — เปิด/ปิด/รีสตาร์ทเซิร์ฟจากปุ่มจริง ไม่ต้องพิมพ์คำสั่ง

🌐 **ใส่ IP เซิร์ฟเองจากหน้าหลักได้** — ไม่ล็อคแค่เซิร์ฟเราแล้ว (เจอบั๊กเก่าอีกจุดบล็อกอยู่ กำลังตามแก้)

🔍 เริ่มไล่เช็คเกมเทียบเซิร์ฟว่าส่วนไหนยังไม่ทำงานจริง เทียบเป้า "เหมือนตอน Nexon เปิด beta" — รายงานละเอียดตามมา
