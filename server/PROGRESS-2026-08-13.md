# บันทึกความคืบหน้า — 13 ส.ค. 2026

## สรุปวันนี้: เชื่อมเกม DurangoV2 เข้ากับ DurangoServer สำเร็จ + ระบบเกมเพลย์รอบแรก

### 1. การเชื่อมต่อเกมจริง (client) เข้ากับ server
- วิเคราะห์ client **Kyllox DurangoV2** (`C:\Users\thana\Projects\DurangoV2`) ด้วย ILSpy (decompile เป็น C#)
- Flow ที่ client ใช้ (โปรโตคอล Nexon เดิม): `GET /knock` → `POST /sessions` → `GET /admission` → `GET /entry` → TCP ต่อ `frontend_addresses` → `Auth` → `Welcome` → `Ready`
- Server เดิมของเรารองรับเกือบหมดแล้ว เหลือแก้:
  - `/knock` ชี้ assetbundle มาที่ server เรา (URL ของ Nexon ตายแล้ว)
  - เพิ่ม static file serving `/assetbundles/*` จาก `DurangoV2_Data\StreamingAssets\AssetBundles`
  - HttpListener bind `localhost` + `127.0.0.1` (bind `*` ต้อง admin)
  - แก้บั๊ก header `Pragma` ผิด enum (ใช้ `Headers.Add("Pragma", ...)`)

### 3. แก้บั๊กโปรโตคอลฝั่ง server
- **เข้าสู่โลกไม่ได้**: `SetChunk` ต้องตอบ `Chunk` **3x3 รอบจุดศูนย์กลาง** (เดิมตอบแค่ 1) — เทียบจาก reference ใน client (`SetCenterChunks`)
- **GameServer ไม่ pump `Connection.Process()`** → เพิ่ม list ของ connection + loop process
- **Say ไม่มี TypeCode** → ลงทะเบียน key 0 พร้อม warning
- **โมเดลตัวละครผิด** → รับ `Display`/`Level`/`EntityType` จาก JSON `player` ใน `/sessions` (แต่ละ id แยกกัน)
- **2 ไอดีเห็นกันไม่ได้** → สาเหตุคือทั้ง 2 ตัวเกมแชร์ save เดียวกัน (entity id ซ้ำ) → แก้ด้วย `AppData2` + เปลี่ยน entity id ใน save

### 4. ระบบเกมเพลย์ (server ใหม่)
| ระบบ | การทำงาน |
|---|---|
| เก็บของ/ตัดไม้ | `Touch` → `Touched` + `Collectible` (generator ตามชนิดจริงจาก `natural` data) → `Collect` → `Timer` → `Collected` + เข้ากระเป๋า; เก็บหมด → `DisappearEntityOnTile` (ของหาย) |
| แชท | `SayInExclusiveChannel`/`SayInConversation` broadcast + `RadiotowerServer` พอร์ต 8192 |
| อิโมจิ/ท่าทาง | `AvailableEmotions` (24 อิโมจิ + 73 ท่า) + `PlayEmoticon` broadcast |
| สกิล/สเตตัส | `Skills` จาก save + `LearnSkill`/`UntrainSkill` (แต้ม 777) + `Statistics` abilities จริง |
| คราฟ | `GetRecipes` (720 สูตร) → `Craft` → `Timer` → `Crafted` + หักวัสดุ + ได้ไอเทม |
| สร้างสิ่งก่อสร้าง | `GetArtifactBlueprints` (570 แปลน) → `OccupyArtifactSite`/`PlaceCapsulatedArtifact` → `AppearArtifact` broadcast (มี `Display.Parts["common"]` = default look + `_burning` ถ้า Burnable) → `BuildArtifact` → `ArtifactBuilt`/`ArtifactCompleted` → `DestructArtifact` |
| กองไฟ (ไอเทมเริ่มต้น) | ใส่ `capsulated_bonfire` ในกระเป๋าตอน spawn + คำสั่ง cheat `add bonfire` |
