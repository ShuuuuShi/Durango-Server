# รายการตรวจเซิร์ฟที่อยู่ในเควส

ทำ 19 ส.ค. 2026 · เทส `--quest-check` รอบ 8 · เปิด/ปิดด้วย `Features.QuestChecklist`

---

## ไอเดีย

เกณฑ์เปิด beta ข้อ 3 คือ **"เล่นด้วยตัวเกมจริง 30 นาที แล้วดูว่าระบบไหนพัง"**
ปัญหาคือคนเทสต้องถือเช็คลิสต์ไว้ข้าง ๆ แล้วไล่ทำเอง — ลืมข้อง่ายมาก และไม่มีหลักฐานว่าทำจริง

**เอารายการนั้นมาใส่เป็นเควสซะเลย** ⇒ หน้าต่างเควสในเกมกลายเป็นเช็คลิสต์

- เดินเล่นไปเรื่อย ๆ ก็รู้เองว่าเหลือระบบไหนที่ยังไม่ได้ลอง
- **ตัวนับมาจาก server** ไม่ใช่ความจำของคนเทส — ข้อไหนขึ้นแปลว่า packet เดินครบวงจรจริง
  (client ส่ง → server ตรวจ → นับ → ตอบกลับ → client วาด)
- เทสผ่านหมดแล้วปิดทิ้งได้ในบรรทัดเดียว โดยไม่แตะสายเควสจริง

## วิธีใช้

```
1. เปิดเซิร์ฟ (Features.QuestChecklist = true อยู่แล้วตอนนี้)
2. เข้าเกม — จะมีข้อความ "[รายการตรวจเซิร์ฟ] เพิ่ม 12 ข้อในหน้าเควส"
3. เปิดหน้าเควส เห็นทั้งสายสอนเล่นและชุดตรวจปนกัน
4. ระหว่างเล่น พิมพ์ `cheat checklist` ดูรายการภาษาไทยพร้อมความคืบหน้า
```

`cheat checklist` พิมพ์ออกมาแบบนี้:

```
[/] 4/4  [ตรวจ] ปลูกเมล็ดข้าวโพด 4 ครั้ง — สร้างแปลงผักก่อน แล้วแตะแปลงเลือก "ปลูก"
[/] 2/2  [ตรวจ] รดน้ำต้นไม้ 2 ครั้ง — ไม่รดน้ำต้นจะตายตอนโตครบ
[ ] 0/1  [ตรวจ] ซ่อมของ 1 ครั้ง — ใช้เครื่องมือจนความทนทานลด แล้วซ่อมด้วยชุดซ่อม
...
— ผ่านแล้ว 7/12 ข้อ
```

## ปิดตอนเทสผ่านแล้ว

`data/config.json`:
```jsonc
"Features": { "QuestChecklist": false }
```

hot-reload 5 วิ — เควสชุดตรวจหายจาก **ทุกทาง** ทันที (รายการ · ตัวนับ · การกดรับรางวัล)
สายสอนเล่น 8 ขั้นไม่กระทบ ไม่ต้อง build ใหม่

## ⚠️ ข้อจำกัดที่ต้องรู้: ชื่อในหน้าเควสเป็นภาษาเกาหลี และไม่ตรงเป๊ะ

`QuestToDo` ที่ server ส่งมีแค่ `{Id, Progress, GoalCount, Finished, Reward}`
**ชื่อ/คำอธิบาย/ไอคอน client หยิบจากตารางของตัวเองด้วย id** ⇒ server เปลี่ยนข้อความไม่ได้เลย

สายสอนเล่นเลือก id ที่ "คำบรรยายเกาหลีตรงกับสิ่งที่ให้ทำ" ได้ครบทุกข้อ
แต่ชุดตรวจทำแบบนั้นไม่ได้ — ข้อมูลเกม **ไม่มีเควสสำหรับ รดน้ำ / ใส่ปุ๋ย / เก็บของเข้ากล่อง / ฟื้นจากตาย** เลย

จึงเลือก id ที่ *ใกล้เคียงที่สุด* แล้วให้ **ข้อความไทยเป็นคำสั่งจริง** (ส่งทาง `Info` + `cheat checklist`)
ยอมได้เพราะชุดนี้เป็นของชั่วคราวสำหรับเทส ไม่ใช่เนื้อหาที่ผู้เล่นจริงจะเห็น

> 💡 **ทำไมไม่ตั้ง id ขึ้นมาเองเลย?** ลองแล้วไม่ได้ —
> `QuestSystem.UpdateQuestTodoProceed` ฝั่ง client ทำ `if (info == null) return;`
> id ที่ไม่มีในตารางเกมจะ **ไม่วาดอะไรเลย** (ไม่พัง แต่ก็ไม่โผล่)

## 🐛 บั๊กที่เจอเพราะทำอันนี้ (แก้แล้ว 2 ข้อ)

### 1. เควสแบบ "ไม่เจาะจง" ถูกนับสองเด้ง

ผู้เรียกยิง `QuestProgress` สองครั้งเสมอ — ทั่วไป 1 ครั้ง เจาะจง 1 ครั้ง:

```csharp
QuestProgress(Goal.Build);                 // สร้างอะไรก็ได้
QuestProgress(Goal.Build, blueprintId);    // สร้าง blueprint นี้
```

แต่ตัวกรองเดิมเช็คแค่ *"ถ้าเควสเจาะจง ต้องตรงกัน"* ⇒ **เควสที่ไม่เจาะจงผ่านทั้งสองครั้ง**

ผลจริง: เควส **"สร้างสิ่งปลูกสร้าง 2 อย่าง" จบตั้งแต่สร้างชิ้นแรก**
(เทสเดิมจับไม่ได้เพราะดูแค่ "เควสเสร็จไหม" ไม่ได้ดูว่าใช้กี่ครั้ง)
เจอเพราะข้อ "สวมอุปกรณ์ 2 ชิ้น" ขึ้น 2/2 ตั้งแต่ใส่ชิ้นเดียว

**แก้:** จับคู่ให้ตรงชนิด — เรียกทั่วไปเข้าเฉพาะเควสทั่วไป · เรียกเจาะจงเข้าเฉพาะเควสที่เจาะจงและตรงกัน

### 2. `cheat questskip` ข้ามเควสต่อแพไปด้วย

`SkipQuestsForTest()` วน `QuestData.All` แล้วเว้นตัวสุดท้ายไว้
พอเพิ่มชุดตรวจต่อท้าย ตัวสุดท้ายกลายเป็นข้อในชุดตรวจ ⇒ **เควสต่อแพถูกมาร์คว่าเสร็จ**
เทสปลายสายจึงไม่มีข้อความฉลองขึ้น

**แก้:** วนเฉพาะ `QuestData.Story` (สายหลัก) ไม่แตะชุดตรวจ

# 🔴 อัปเดตหลังเล่นจริงรอบแรก — เจอ 2 เรื่องใหญ่

## 1. เห็นแค่ 2 เควส เพราะ `display_on_hud` ของเกม

ไล่ดูตาราง `quests_for_client` ทั้ง 1,386 อัน พบว่า **มีแค่ 126 อันที่ `display_on_hud: true`**
และใน 20 id ที่เราเลือกใช้ มีแค่ **2 อัน** ที่เป็น true:

| id | hud | หมวดในข้อมูลเกม |
|---|---|---|
| `mainstory_chapter1_5` | ✅ | sunset |
| `mainstory_chapter4_6` | ✅ | sunset |
| อีก 18 อัน | ❌ | permanent / daily / event_* |

ฝั่ง client `QuestSystem.UpdateQuestTodoProceed` ทำ `if (info == null || !info.DisplayOnHud) return;`
⇒ เควสที่ hud=false **ไม่ถูกวาดบน HUD เลย** ตรงกับที่เห็นเป๊ะ ๆ

**แก้แล้วบางส่วน:** ทำเป็น **แท็บแยก** (ข้อ 2) ซึ่งใช้เส้นทางคนละอันกับ HUD
**ที่ยังเหลือ:** ถ้าอยากให้ขึ้นบน HUD ด้วย ต้องเลือก id จาก 126 อันที่ hud=true
(ซึ่งเกือบทั้งหมดเป็นเนื้อเรื่อง `mainstory_chapter*` — คำบรรยายเกาหลีจะไม่ตรงกับสิ่งที่ให้ทำเลย)

## 2. ทำเป็นแท็บแยกแล้ว

`QuestCategory.Name` มาจาก **server** ไม่ใช่ตารางในตัวเกม ⇒ ตั้งชื่อแท็บภาษาไทยได้ทันที

```csharp
QuestData.ChecklistCategory = "server_checklist";   // แท็บชื่อ "รายการตรวจเซิร์ฟ"
```

- `SendQuestCategories` ส่งแท็บนี้เพิ่ม (เฉพาะตอน `Features.QuestChecklist = true`)
- `SendQuestList` **แยกเป็นคนละ packet ต่อหมวด** — เดิมยัดทุกเควสลงหมวดเดียว
  ถ้าไม่แยก แท็บใหม่จะว่างเปล่าเพราะ client เก็บรายการตามหมวดที่ packet บอกมา
- จุดแดงบนแท็บ (`UnreceivedCount`) นับเฉพาะหมวดของตัวเอง
