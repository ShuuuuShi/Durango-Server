# บอทขับเกมจริง — BotBridge (ในเกม) + GameBot.exe (โปรแกรมแยก)

**สิ่งที่ได้:** บอทที่**เล่นเกมจริงที่เปิดอยู่**ให้เอง — เดินไปหาไม้/หิน · เก็บของ · ล่าสัตว์ · แล่ซาก ·
กินเมื่อหิว — ทั้งหมดนี้**ไม่แตะเมาส์/คีย์บอร์ด** และเป็น**โปรแกรม exe แยกจากตัวเกม**

**ทำไมถึงทำได้:** ฝัง "สะพาน" (BotBridge) เข้าไปในตัวเกมผ่านซอร์ส `client/BotBridge.cs`
(compile เข้า `Assembly-CSharp.dll` ด้วย `tools/build-client.ps1` ตามเดิม)
แล้ว GameBot.exe ต่อ TCP เข้าสะพานเพื่ออ่านสถานะและสั่งเล่น

## หลักการ: ไม่แย่งเมาส์ได้ยังไง

| งาน | ผ่านอะไร |
|---|---|
| กดปุ่ม UI | `UICamera.GetInputTouchCount/GetInputTouch` — ฉีด fake touch เข้า NGUI pipeline เดิม (raycast → OnPress → OnClick) ตัวเกมคิดว่าโดนนิ้วแตะ |
| เดิน | `PlayerController.MoveToPosition()` — เมธอดเดียวกับที่การแตะพื้นเรียก ตัวเกมเดิน+รันอนิเมชัน+ส่ง Move packet เอง |
| เก็บของ/แล่ซาก | `InteractionSystem.SetInteractionTarget()` + `SendTouchMsg()` + กดเมนู Collect — ทางเดียวกับที่ผู้เล่นแตะของธรรมชาติจริง |
| ล่าสัตว์ | `InteractionSystem` กดเมนู Attack → `CombatSystem.UseBattleAction()` — ทางเดียวกับปุ่มโจมตี |
| กินของ | `InventorySystem.UseItem()` — ทางเดียวกับปุ่มใช้ของ |

**ผลลัพธ์:** server ได้รับ packet ของจริงทุกอย่าง (กันโกง GP-08/09/12 ยังบังคับเหมือนเดิม)
และเห็นตัวละครในเกมเดิน/เก็บ/ต่อสู้จริง — ใช้เทสเซิร์ฟแบบยาว ๆ ได้โดยไม่ต้องนั่งกดเอง

## วิธีติดตั้ง (ครั้งเดียว)

```bash
powershell -File tools\build-client.ps1     # build client + วาง DLL ลงเกม (มี BotBridge แล้ว)
dotnet publish game-bot -c Release -o game-bot\publish   # สร้าง GameBot.exe
```

## วิธีใช้

1. เปิดเซิร์ฟ + เปิดเกม + เข้าเกมให้ตัวละครยืนอยู่ (เมนูข้อ 1 ใน `เทสเกม.bat`)
2. รันบอท:

```bash
# วงจรอัตโนมัติ: เก็บของ → กินเมื่อหิว → ล่าสัตว์เป็นระยะ → แล่ซาก (5 นาที)
game-bot\publish\GameBot.exe --bot 127.0.0.1 8192 5

# สั่งเอง (พิมพ์คำสั่งทีละบรรทัด)
game-bot\publish\GameBot.exe --console 127.0.0.1 8192

# สั่งรวดเดียวแล้วออก
game-bot\publish\GameBot.exe --cmd "state;move x=8200 y=35600;gather"
```

หรือรันจากซอร์ส: `cd game-bot; dotnet run -- --bot 127.0.0.1 8192 5`

## คำสั่ง (โหมด console)

| คำสั่ง | ทำอะไร |
|---|---|
| `state` | สถานะทั้งหมด: ตำแหน่งผู้เล่น (พิกัดโลก + tile) · เลือด/สตามินา · ของในกระเป๋า (รวมชิ้นซ้ำ + tag) · สัตว์รอบตัว · ของธรรมชาติรอบตัว · เมนูปฏิสัมพันธ์ · โหมดต่อสู้ |
| `move x=<โลกX> y=<โลกZ>` | เดินไปตำแหน่งโลก (tile*200+100 — เดินจริง รันอนิเมชัน ส่ง Move packet) |
| `stop` | หยุดเดิน |
| `tap x=<px> y=<px>` | แตะ UI ที่พิกัดจอ (ล่างซ้าย = 0,0 เหมือน Input.mousePosition) |
| `gather [id=...]` | แตะของธรรมชาติ (ไม่ระบุ = ตัวใกล้สุด) แล้วกด Collect ให้อัตโนมัติ |
| `butcher [id=...]` | แล่ซากสัตว์ (เฉพาะ IsLootable) |
| `attack [id=...]` | แตะสัตว์แล้วกด Attack — เข้าโหมดต่อสู้แล้วต้องตามด้วย `action` |
| `action [id=...]` | ใช้สกิลต่อสู้ (ไม่ระบุ = เลือกท่าโจมตีที่ใช้ได้เอง) |
| `menu action=<Collect\|Attack>` | กดปุ่มเมนูปฏิสัมพันธ์ของเป้าหมายปัจจุบัน |
| `use [id=<itemId>]` | ใช้ของ (ไม่ระบุ = ของที่กินได้ชิ้นแรก) |
| `log text=...` | เขียน log เข้าเกม (Debug.Log) |

ตอบกลับเป็น JSON 1 บรรทัด — เอาไปต่อยอดสคริปต์ได้ (`{"ok":true,...}` หรือ `{"ok":false,"error":"..."}`)

## วงจรอัตโนมัติ (`--bot`)

1. รอจนผู้เล่นเข้าเกม (ข้าม title/menu ไปให้)
2. วน: หาของธรรมชาติใกล้สุด → เดินไป → แตะ → รอเก็บเสร็จ → ตัวถัดไป
3. กินเมื่อสตามินา < 30% หรือเลือด < 50% (เลือกของที่ tag เป็นอาหาร)
4. ล่าสัตว์ทุก ๆ 3 รอบการเก็บ → ตีจนตาย → เดินไปแล่ซาก
5. กระเป๋าเต็ม = กินของแทนการเก็บ (ยังไม่มีระบบทิ้งของ)
6. รู้จำจุดที่เก็บไม่ได้แล้ว (โดน Abort) — ไม่กลับไปวนตันจุดเดิม

สรุปผลตอนจบ: จำนวนเดิน/เก็บ/ล่า/ตี/กิน/พลาด

## ปัญหาที่เจอแล้วแก้

- **UI ต้องกดเองไม่ได้** → fake touch เข้า UICamera pipeline เดิม (ไม่ต้องแตะเมาส์จริง)
- **ของธรรมชาติไม่รู้จัก** → bridge อ่านจาก `InteractionSystem.SearchPropObjects` (ตัวเดียวกับที่เกมใช้ตอนแตะ)
- **เมนู Collect มีหลายปุ่ม** → bridge เลือกปุ่มแรกที่ใช้ได้ แล้วรอ timer ของ GatheringSystem จบ
- **กด Attack แล้วเมนูหาย** → bridge ถือว่างานจบเมื่อเมนูว่าง/ไม่มี timer — บอทเลยเข้าโหมดตีต่อได้

## ข้อควรรู้

- BotBridge เปิดพอร์ต 8192 (ตั้งใหม่ด้วย env `DURANGO_BOT_PORT`) — ผูก localhost เท่านั้น
- ตัวเกมต้องโหลดซีนจริงก่อน (BotBridge เริ่มทำงานตั้งแต่เข้าเกมแล้ว แต่คำสั่ง gather/attack/move
  ต้องมีผู้เล่นในเกม)
- บอทขับ**ตัวละครที่ล็อกอินอยู่ในเกม** — ต้องเปิดเกม + เข้าเกมให้ตัวละครยืนก่อน
- ถ้าคนจริงกำลังเล่นอยู่ บอทจะแย่งบังคับตัวละคร — ใช้เฉพาะตอนเทส
