# 📢 แจ้งย้ายเซิร์ฟ Durango — ต้องลง Tailscale ก่อนเข้าเล่น

สวัสดีทุกคนครับ 🦕

ตอนนี้เซิร์ฟ VPS เดิมมีปัญหาเข้าไม่ได้ และ ณ ตอนนี้ยังไม่มีงบพอจะเช่า VPS ใหม่ 💸 เลยขอย้ายมารันเซิร์ฟที่บ้านแทนชั่วคราวก่อนนะครับ — แต่เน็ตบ้านติด CGNAT (ต่อจากข้างนอกตรงๆ ไม่ได้) เลยต้องใช้ตัวช่วยชื่อ **Tailscale** (ฟรี 100%) ในการเชื่อมต่อแทน

ขั้นตอนไม่ยาก ทำตามนี้ได้เลยครับ 👇

---

## 1️⃣ สมัคร + ลง Tailscale

1. เข้า 🔗 https://tailscale.com/download
2. เลือกดาวน์โหลดตามเครื่องที่ใช้ (Windows/Mac/มือถือมีให้หมด)
3. ติดตั้งแล้วเปิดโปรแกรม → ล็อกอิน (ใช้ Google/Microsoft/GitHub account สมัครฟรีได้เลยถ้ายังไม่มี) ✅

## 2️⃣ รับสิทธิ์เข้าเซิร์ฟ

1. คลิกลิงก์นี้ 🔗 **https://login.tailscale.com/admin/invite/uVPapaMPTtH7N2TBMssQ11**
2. ล็อกอินด้วยบัญชี Tailscale ที่เพิ่งสมัคร
3. กด **Accept** รับเครื่องเซิร์ฟเข้ามา 🎉 (จะเห็นเครื่องชื่อ `linuxserver` โผล่ในแอพ Tailscale ของตัวเอง)

> 🔒 ปลอดภัย 100% — เข้าถึงได้แค่ตัวเซิร์ฟเกมเท่านั้น ไม่เห็นเครื่องอื่นหรือไฟล์อื่นในบ้านเลย

## 3️⃣ โหลดตัวเกม

1. โหลดจาก GitHub Release 🔗 https://github.com/SuperCodeTH/Durango-TH-Client/releases/latest
2. แตกไฟล์ zip ไปไว้โฟลเดอร์ไหนก็ได้ 📂

## 4️⃣ ตั้งค่าเซิร์ฟ

1. เปิดไฟล์ `server.txt` ในโฟลเดอร์เกม ด้วย Notepad
2. ลบที่อยู่เดิม แล้วใส่แทนด้วย:
   ```
   100.84.186.56
   ```
3. เซฟไฟล์ ปิด Notepad

## 5️⃣ เข้าเล่นได้เลย! 🎮

ดับเบิลคลิก `เล่นเกม.bat` — ต่อได้เลยครับ ถ้าเข้าไม่ได้เช็คก่อนว่า Tailscale เปิดอยู่ (ไอคอนสีเขียวที่ system tray)

---

### ⚠️ สำหรับคนที่เคยโหลด/เล่นอยู่แล้ว

ต้องแก้ `server.txt` เป็น `100.84.186.56` เองด้วยนะครับ (ระบบอัปเดตอัตโนมัติจะไม่แตะไฟล์นี้ให้ กันไม่ให้ค่าที่ตั้งเองหาย) ทำตามข้อ 1️⃣ 2️⃣ 4️⃣ ด้านบนพอ ไม่ต้องโหลดใหม่ทั้งชุด
