# 🏝️ Durango Private Server — อัปเดตความคืบหน้า

**สถานะตอนนี้: เล่นด้วยกันได้จริงแล้ว กำลังไล่เติมระบบเกมเพลย์ทีละอย่าง**

เราเขียนเซิร์ฟเวอร์ขึ้นมาใหม่ทั้งตัวเพื่อให้ตัวเกม Durango ที่ปิดไปแล้วกลับมาเล่นได้อีกครั้ง
ตอนนี้ทดสอบเข้าเกมพร้อมกัน 2 คน เห็นกัน เดินด้วยกันได้แล้ว 🎉

## ✅ เล่นได้แล้ว

- เข้าเซิร์ฟพร้อมกันหลายคน เห็นตัวละครกันจริง เดินแล้วซิงก์ตรงกัน
- แชท + อิโมติคอน
- เก็บของจากธรรมชาติ (ตัดไม้ เก็บหิน) — ของหมดแล้วหายจริง ทุกคนเห็นตรงกัน
- คราฟต์ไอเทม
- สร้างสิ่งปลูกสร้าง วางของ ทุบทิ้ง
- เรียนสกิล
- 🆕 **ใส่อุปกรณ์ได้แล้ว** — ใส่ขวาน ใส่เสื้อ แล้วคนอื่นเห็นตัวเราเปลี่ยนด้วย
- 🆕 **ความคืบหน้าไม่หายแล้ว** — ของในกระเป๋า สกิล ตำแหน่งที่ยืน บ้านที่สร้าง ต้นไม้ที่ตัดไป
  ทั้งหมดถูกเซฟ ปิดเซิร์ฟเปิดใหม่ก็ยังอยู่

## ⚡ แก้ปัญหาใหญ่เบื้องหลัง

เจอคอขวดที่ทำให้เซิร์ฟเวอร์รับคำสั่งจากผู้เล่นได้แค่ประมาณ **64 ครั้งต่อวินาทีต่อคน**
ผลคือยิ่งเล่นนานยิ่งหน่วง เดินแล้วตัวขยับตามช้าลงเรื่อย ๆ จนเล่นไม่ไหว

แก้เรียบร้อยแล้ว ตอนนี้เพดานสูงขึ้นเกือบพันเท่า ไม่ใช่คอขวดอีกต่อไป

นอกจากนี้ยังแก้อีกหลายจุด เช่น
- คนที่เข้ามาทีหลังเคยไม่เห็นบ้านที่คนอื่นสร้างไว้ → แก้แล้ว
- คนที่เข้ามาทีหลังเคยเห็นคนอื่นยืนผิดตำแหน่ง → แก้แล้ว
- สองคนตัดต้นไม้ต้นเดียวกันเคยได้ของครบทั้งคู่ (ของก๊อป) → แก้แล้ว
- แชทเคยขึ้นแต่ข้อความไม่มีชื่อคนพูด → แก้แล้ว
- บ้านคนอื่นเคยโดนทุบได้ → ตอนนี้ตรวจเจ้าของแล้ว

## 🚧 ยังไม่มีในตอนนี้

อยากให้ทุกคนเห็นภาพตรงกันว่าอะไรที่ยังเล่นไม่ได้

- สัตว์ป่า / ระบบต่อสู้ / ตาย-ฟื้น
- ค่าหิว ค่าล้า สตามินา
- ปาร์ตี้ / แคลน / เพื่อน / เมล
- วาร์ปข้ามเกาะ
- กล่องเก็บของ / ฟาร์มปลูกพืช / เพ็ท
- ระบบเควส

ตอนนี้ยังเป็นเกาะเดียว เน้นสำรวจ เก็บของ คราฟต์ สร้างบ้าน อยู่ด้วยกัน

## 🔜 กำลังทำต่อ

1. ค่าสถานะเอาชีวิตรอด (หิว / ล้า / สตามินา)
2. สัตว์ป่า + ระบบต่อสู้ + ตาย-ฟื้น
3. กล่องเก็บของ

จะทยอยอัปเดตให้เรื่อย ๆ ครับ 🙏
