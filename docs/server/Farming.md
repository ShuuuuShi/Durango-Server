```
สร้าง farm_tile → ลงเมล็ด → รดน้ำ + ใส่ปุ๋ย → รอโต → เก็บเกี่ยว → แปลงว่าง ปลูกใหม่ได้
                                    ↘ ไม่รดน้ำ → ต้นตาย → ต้องถอนทิ้ง
```

## 1. เรื่องที่ต้องรู้ก่อนอ่านโค้ด

### 1.1 แปลงผัก = สิ่งปลูกสร้าง ไม่ใช่ entity ชนิดใหม่

`farm_tile_01..04` เป็น blueprint ที่มี component **`Growable`** สถานะการปลูกไปอยู่ที่
`ArtifactState.Farming` ของ artifact ชิ้นนั้น

⇒ ทุกอย่างที่ระบบสิ่งปลูกสร้างมีอยู่แล้วใช้ได้เลย: เจ้าของ · เพดาน 40 ชิ้น/คน ·
พื้นที่ทับซ้อน · ระยะเอื้อม · การมองเห็น (interest management)

### 1.2 **การเก็บเกี่ยวไม่มี packet ของตัวเอง**

ฝั่ง client ไม่มี `Interaction.Harvest` เลย — มีแค่ 4 อัน:

| เลข | ปุ่ม | packet |
|---|---|---|
| 508 | ปลูก | `PlantSeed` |
| 509 | ใส่ปุ๋ย | `FertilizePlant` |
| 510 | รดน้ำ | `WaterPlant` |
| 511 | ถอน | `UprootPlant` |

เก็บเกี่ยวใช้เมนู **"เก็บ" (506)** ชุดเดียวกับของธรรมชาติ ⇒ `Touch` → `Collectible` → `Collect`
พอโตแล้ว server จะตั้ง `Generator` ให้ artifact ชิ้นนั้น เหมือนที่ทำกับซากสัตว์เป๊ะ ๆ

### 1.3 เมนูฝั่ง client มาจาก `Touched.Interactions` ล้วน ๆ

ถ้า server ไม่ใส่เลข interaction ให้ ผู้เล่นแตะแปลงแล้วจะ**ไม่มีปุ่มอะไรเลย**
(เป็นบทเรียนเดียวกับตอนแตะสัตว์แล้วปุ่มโจมตีไม่ขึ้น)

`AddFarmInteractions()` เลือกเมนูตามสถานะ:

| สถานะแปลง | เมนูที่ให้ |
|---|---|
| ว่าง | ปลูก |
| กำลังโต | รดน้ำ · ใส่ปุ๋ย · ถอน |
| โตแล้ว | เก็บ · ถอน |
| ตายแล้ว | ถอน |

## 2. ข้อมูลที่ใช้ — `CropData.cs` (สร้างอัตโนมัติ)

```bash
python scripts/extract_crops.py "../game/DurangoV2_Data/resources.strings.txt" \
       ServerCore/CropData.cs ServerCore/ItemTagData.cs
```

ดึงจาก 4 ตารางในไฟล์เดียวกัน:

| ตาราง | เอาอะไรมา |
|---|---|
| `crops` | เวลาโต · น้ำ · ปุ๋ย · ไบโอมที่ชอบ · ผลผลิต · ความทน |
| `crop_data` | ชื่อ/ไอคอน/เลเวลสูงสุดของเมล็ด |
| `generator_client_data` | ชื่อ/ไอคอนของผลผลิต (`corn_crop`, `corn_seed_crop`) |
| `performance` | ปุ๋ยที่ไอเทมให้ · ความจุภาชนะตักน้ำ |

### กับดัก 2 อันที่เสียเวลาไปแล้ว

**ก. asset `performance` โผล่ 3 ก้อน และมี asset ดิบแทรกกลาง**

กฎเดิม "เจอบรรทัดชิดซ้าย = จบ asset" ใช้ไม่ได้ เพราะมี `color_cloth.raw` (ไบนารี) แทรกอยู่กลาง asset
⇒ ตาราง `fertilizer` ที่อยู่ท้าย ๆ หายไปทั้งก้อน (สกัดได้ปุ๋ย 0 ชนิด)
แก้ด้วย `read_subtable()` ที่ **นับปีกกา** แทนการดูการเยื้อง

**ข. ข้อมูลเกมไม่มี tag ของผลผลิตเลย**

`corn_crop` โผล่ทั้งไฟล์แค่ 3 ที่ (crops · collectible_names · generator_client_data)
ไม่มีที่ไหนบอกว่ามันเป็น "ธัญพืช" ⇒ **เอาไปทำอาหารไม่ได้**

แก้: เดา tag ของผลผลิตจาก **tag ของเมล็ด** โดยตัด `plantable` ออก
`corn_seed` = eatable/grain/plantable/vegetable ⇒ `corn_crop` = eatable/grain/vegetable
เมล็ดที่มี tag แค่ `plantable` อย่างเดียว (28 ชนิด) เดาจากไอคอนต่ออีกชั้น (ผลไม้/ผัก/เห็ด/ดอกไม้/เส้นใย)
ที่เหลือ 15 ชนิดปล่อยว่างไว้ (ต้นไม้ประดับ/ดอกไม้ ที่ยังไม่มีสูตรมารองรับอยู่ดี)

> เหตุผลเดียวกับที่ `ItemTagData` เดา tag ชนิดเครื่องมือจากชื่อ prototype —
> ตารางฝั่ง server ของ NEXON ไม่ได้ติดมากับ client

## 3. กติกาที่เราเขียนเอง (ข้อมูลเกมไม่ได้บอก)

### 3.1 เวลาโต — ต้องย่อ

ข้อมูลเกมเป็นของเกมออนไลน์จริง:

| พืช | เวลาโตจริง |
|---|---|
| ข้าวโพด | 5 นาที |
| มันฝรั่ง | 30+ นาที |
| ต้นไม้ผล (กล้วย/แอปเปิล) | **21 ชั่วโมง** |

`Farming.GrowthScale` ค่าเริ่มต้น **0.05** = ย่อเหลือ 1/20 (ต้นไม้ผล → ~1 ชม.)
ใส่ `1.0` ถ้าอยากได้เวลาเท่าเกมจริง · มีพื้นขั้นต่ำที่ `MinGrowSeconds` (20 วิ)

### 3.2 น้ำ — ตัดสินตอนโตครบว่ารอดหรือตาย

ใช้ `survivability` ของพืชเป็นเกณฑ์ความใจดี:

| น้ำที่ได้ | ผล |
|---|---|
| ≥ ที่ต้องการ | รอดเต็ม ได้ผลผลิตตามปุ๋ย |
| ≥ ที่ต้องการ × survivability | รอดแบบไม่สมบูรณ์ — ได้ 1 ชิ้นเท่านั้น |
| น้อยกว่านั้น | **ตาย** เก็บไม่ได้ ต้องถอนทิ้ง |

(ข้าวโพด survivability 0.9 · ต้องการน้ำ 2 ⇒ ต่ำกว่า 1.8 = ตาย)

### 3.3 ปุ๋ย — ตัดสินจำนวนผลผลิต

```
ผลผลิต = 1 + round(additional_product × (ปุ๋ยที่ใส่ / ปุ๋ยที่ต้องการ) × FertilizerYieldScale)
```

ข้าวโพด: `additional_product` = 5 ⇒ ใส่ปุ๋ยเต็ม 20 หน่วยได้ 6 ชิ้น · ไม่ใส่เลยได้ 1 ชิ้น

### 3.4 ไบโอม

`preference_land` ของพืชเทียบกับไบโอมของ tile ที่แปลงตั้งอยู่:

| | ผล |
|---|---|
| ตรงกับที่ชอบ | `Excelent` — ปกติ |
| พืชไม่เลือกที่ | `Normal` — ปกติ |
| ผิดไบโอม | `Bad` — โตช้าลง ×1.5 และ **ได้ผลผลิตครึ่งเดียว** |

ตอนปลูกผิดไบโอมจะมีข้อความเตือนขึ้นให้ผู้เล่นรู้ตัว

### 3.5 เก็บเกี่ยวได้เมล็ดคืน

พืช 51 จาก 53 ชนิดมี generator `<เมล็ด>_crop` ⇒ เก็บแล้วได้เมล็ดกลับมา 1 เม็ด
(`Farming.SeedYield`) ⇒ ปลูกต่อได้เรื่อย ๆ โดยไม่ต้องหาเมล็ดใหม่
(ยกเว้น `apple_seed` กับ `carnation_seed` ที่ข้อมูลเกมไม่มีเมล็ดคืน)

### 3.6 ตักน้ำ

`DrawWater` ต้องมี **ภาชนะ** (tag `container`) และยืนใกล้แหล่งน้ำจริง
ไบโอมที่ตักได้คือ 11-14 (ทะเลเย็น/ทะเลอุ่น/แม่น้ำ/ทะเลสาบ) ตามที่ข้อมูลเกมระบุไว้ที่
`put_in_container_infos.water` · จำนวนน้ำที่ได้ = ความจุของภาชนะ ตัดที่ `MaxWaterCarryPerDraw`

## 4. ช่องโหว่ที่ปิดไว้แล้ว

| ช่องโหว่ | ปิดยังไง |
|---|---|
| ปลูกโดยไม่มีเมล็ด | ต้องหาไอเทมเจอในกระเป๋าจริง แล้วหักหลังลงแปลงสำเร็จ |
| ปลูกของที่ไม่ใช่เมล็ด | ต้องอยู่ใน `CropData.ById` |
| ปลูกทับต้นเดิม | แปลงที่มี `FarmPlot` อยู่แล้วปฏิเสธ |
| รดน้ำด้วยของอะไรก็ได้ | ต้องมี tag `water` · ปุ๋ยต้องมีค่าใน `FertilizerPower` |
| **ส่ง id ไอเทมชิ้นเดียวซ้ำ 10 ครั้งในลิสต์เดียว** | `HashSet` กันซ้ำก่อนหัก |
| ปลูก/เก็บแปลงของคนอื่น | `CanModifyArtifact` (เจ้าของ + รายชื่อสถาปนิก) |
| ทำจากอีกฟากเกาะ | `IsWithinReach` ใช้ tile ที่ **server จำไว้** ไม่ใช่ `msg.Tile` |
| เก็บเกินจำนวนที่มี | `TryReserveCorpsePart` จองแบบอะตอมมิก (ทางเดียวกับแล่ซาก) |
| **รีสตาร์ทเซิร์ฟแล้วผลผลิตเกิดใหม่** | เซฟ `RemainProduct`/`RemainSeed` จาก generator จริง แล้วโหลดกลับตามนั้น |
| ยิงรัว ๆ จน `_deferred` ล้น | `MaxPendingActions` |

> 💡 **ข้อ "รีสตาร์ทแล้วเกิดใหม่" เป็นข้อที่เกือบพลาด** — ถ้าเซฟแค่ "โตแล้ว"
> ตอนโหลดกลับต้องคิดผลผลิตใหม่ ซึ่งจะได้เต็มจำนวนทุกครั้ง = ปั๊มของด้วยการรีสตาร์ทเซิร์ฟ
> เทสไว้ที่ `--farm-resume-check` (รัน 2 เฟส คั่นด้วยการรีสตาร์ทเซิร์ฟ)

## 5. ค่าที่ปรับได้ใน `data/config.json`

```jsonc
"Farming": {
  "GrowthScale": 0.05,              // ตัวคูณเวลาโต (0.05 = เร็วกว่าเกมจริง 20 เท่า)
  "MinGrowSeconds": 20,
  "WaterPerItem": 1,
  "FertilizerYieldScale": 1,        // ตัวคูณผลผลิตที่ได้จากปุ๋ย

  "MaxWaterCarryPerDraw": 5,
  "StaminaCostPlant": 6,
  "StaminaCostTend": 3,
  "StaminaCostDraw": 3,

  "TendSeconds": 1.5,
  "UprootSeconds": 2,
  "HarvestSeconds": 2,
  "DrawWaterSeconds": 2,
```

## 8. ที่ยังไม่ได้ทำ

- **เครื่องรดน้ำอัตโนมัติ** (`Sprinkle` / `Sprinklable`) — packet มีแล้วฝั่ง client แต่ยังไม่มี handler
- **เร่งโตด้วยเจม** (`RapidGrowthCost`) — ส่ง null ไปเสมอ (ยังไม่มีระบบเงินตรา)
- **ปุ๋ยพิเศษ** (`AppliedCropBooster` / `BoosterLevel`) — ข้อมูลเกมมี tag `fertilizer_boost_*` แต่ยังไม่ได้ทำ
- **สมุดสารานุกรมพืช** (`FarmingEncyclopedia`) — client มี UI ครบ ยังไม่มีใครตอบ
- **เควสสายเพาะปลูก** — `QuestData.Goal.Plant` / `Goal.Harvest` ต่อสายไว้แล้ว แต่ยังไม่มีเควสอันไหนใช้
