# เกาะแยกตามช่วงเลเวล (Beta 1.1 — ยังไม่เสร็จ)

**ไฟล์:** `ServerCore/IslandRegistry.cs` · `ServerCore/ServerPlayer.Travel.cs` · ทะเบียนที่ `server/data/islands.json`

สถานะ: **โครงสร้างพื้นฐานทำงานแล้ว · การเดินทางจากในเกมยังทำไม่ได้ · มีบั๊กค้าง 1 ข้อ** (ดูท้ายไฟล์)
เปิดเซิร์ฟแบบเดิม (ไม่ใส่ `--island`) ยังปกติทุกอย่าง — โหมดเกาะเป็นของเสริมที่ต้องสั่งเปิดเอง

---

## 1. ทำงานยังไง

**1 เกาะ = 1 process** คนละ terrain · คนละไฟล์เซฟโลก · คนละ config · คนละพอร์ต
แต่ **ตัวละครใช้ไฟล์เซฟร่วมกันทุกเกาะ** (`saves/players/`) ของกับเลเวลจึงตามไปด้วย

```bash
cd server
dotnet run -- --island isle01 --enable-cheat --admin gm      # เกาะเริ่มต้น 8190/8191
dotnet run -- --island isle02 --enable-cheat --admin gm      # เกาะป่าลึก  8290/8291
```

| อะไร | อยู่ที่ไหน |
|---|---|
| ทะเบียนเกาะ | `data/islands.json` (ทุกเกาะอ่านไฟล์เดียวกัน) |
| ค่าสมดุลของเกาะ | `data/islands/<id>/config.json` (สร้างให้อัตโนมัติ) |
| โลกของเกาะ | `saves/worlds/<id>.json` — บ้าน/กล่อง/ของธรรมชาติ **แยกกันต่อเกาะ** |
| ตัวละคร | `saves/players/<id>.json` — **ใช้ร่วมกัน** |

### ทะเบียนเกาะ

```json
{ "Id": "isle02", "Name": "เกาะป่าลึก", "Terrain": "ri40tr",
  "MinLevel": 10, "MaxLevel": 20, "RequiredLevel": 8,
  "Host": "127.0.0.1", "GatewayPort": 8290, "GamePort": 8291 }
```

- `MinLevel`/`MaxLevel` = ช่วงเลเวลสัตว์บนเกาะ — **ตอนสร้าง config ให้เกาะใหม่ ตารางสัตว์มาตรฐาน
  (lv1-10) จะถูกเลื่อนช่วงให้ตรงกับเกาะโดยอัตโนมัติ** เช่นเกาะ lv10-20 กิ้งก่าจะกลายเป็น lv10-12
- `RequiredLevel` = ต้องเลเวลเท่านี้ถึงเดินทางมาได้
- `Terrain` = ไฟล์ใน `data/terrains/` — มีให้ใช้ 13 เกาะ (`pe10gr_1-5` `ri35te` `ri35de` `ri40tr`
  `ri45sa` `ri50sn` `ri55tu` `ra60sw` `ua60vol`) **ตัวเลขในชื่อไฟล์เป็นของเกมเดิม ไม่ได้บังคับเลเวลสัตว์ของเรา**
- ⚠️ ห้ามใช้พอร์ต **8390/8391** — ตัวเกมมี server ของตัวเองอยู่ตรงนั้น

### ตัวละครข้ามเกาะ

`PlayerSave.LastIsland` จำว่าออกจากเกมครั้งล่าสุดที่เกาะไหน
เข้ามาคนละเกาะกับที่จำไว้ = **เกิดที่จุดเข้าเกมของเกาะใหม่** (ไม่ใช่พิกัดเดิมซึ่งอาจเป็นกลางทะเลของอีกเกาะ)

**เทสแล้วได้จริง:** เลเวล 10 · exp 409 · แต้มสกิล 27 · ของ 3 ชิ้น เดินทาง isle01 → isle02 ครบทุกอย่าง
ส่วนบ้าน/กล่องไม่ตามไปด้วย (อยู่กับเกาะ) ซึ่งเป็นพฤติกรรมที่ตั้งใจ

### คำสั่ง

```
cheat islands              # รายชื่อเกาะ + บอกว่าเลเวลถึงไหม + ตอนนี้อยู่เกาะไหน
cheat travel isle02        # เดินทาง (ตรวจ: มีเกาะจริง · ไม่ใช่เกาะเดิม · เลเวลถึง · ไม่ได้ตายอยู่)
control <ชื่อ> travel isle02
```

## 2. ที่ยังทำไม่ได้: เดินทางจากในเกม ★

`TravelTo()` ทำครบทุกอย่างแล้ว — ตรวจเงื่อนไข · เซฟตัวละคร · ส่ง `Info "##goto <host:port>"` ·
ส่ง `Emigrated` (packet ของเกมเอง ทำให้ client ตัดการเชื่อมต่อกลับหน้าไตเติ้ล)

**แต่ client จะต่อกลับมาที่เกาะเดิม** เพราะ:

```csharp
// client/Durango.Offline/Server.cs
public static void ConnectTo(string ip)
{
    string gatewayUrlRoot = "http://" + ip + ":" + 8190;   // ← พอร์ต gateway ฮาร์ดโค้ด
```

และไม่มี packet ไหนของเกมที่ส่ง "ที่อยู่เซิร์ฟใหม่" มาให้ client เลย

### ทางเลือกที่สำรวจแล้ว

| ทาง | ได้ไหม | ปัญหา |
|---|---|---|
| ให้แต่ละเกาะใช้ IP คนละตัว (127.0.0.2 ...) พอร์ต 8190 เท่ากัน | ❌ | ทดสอบแล้ว: `HttpListener` และ TCP bind ที่ 127.0.0.2 ได้ **Access denied** ต้องเป็น admin + `netsh http add urlacl` |
| **patch client** ให้ `ConnectTo` รับ `host:port` + ดักข้อความ `##goto` แล้วต่อใหม่เอง | ✅ น่าจะได้ | ต้องเขียน IL เพิ่มใน `tools/DllPatcher` (มีโครงอยู่แล้ว — เคย patch `DURANGO_AUTOCONNECT` กับเมนูที่ซ่อนมาแล้ว) |
| gateway ตัวเดียวหน้าเกาะทั้งหมด แล้ว route ตามผู้เล่น | ⚠️ | `/entry` คืนพอร์ตเกมได้ (ไม่ฮาร์ดโค้ด) แต่ **terrain ก็เสิร์ฟจาก gateway เดียวกัน** ต้องแยกตามผู้เล่นซึ่ง `/terrains/1` ไม่มีตัวระบุผู้เล่นมาให้ |

**ทางที่แนะนำ: patch client** — ตรงกับที่โปรเจกต์ทำอยู่แล้วและไม่ต้องให้ผู้เล่นรันอะไรด้วยสิทธิ์ admin

## 3. 🐛 บั๊กค้าง: โหมดเกาะทำให้ `--gp-check` ตก 2 ข้อ

```
[ตก] แตะสัตว์เป็น ๆ แล้วได้ปุ่มโจมตี — victim=animal_xxx reply.id= name= lv=0 touched=1 interactions=[null]
[ตก] แตะซากแล้วได้เมนูแล่เนื้อ — touched=1 parts=0
```

**ตรวจแล้วรู้อะไรบ้าง**
- เปิดเซิร์ฟแบบเดิม (ไม่ใส่ `--island`) → **45/45 ผ่านหมด** · ใส่ `--island isle01` → ตก 2 ข้อนี้ทุกครั้ง
- ทั้งสองโหมดใช้ binary ตัวเดียวกัน และ terrain เดียวกัน (`ri35te`)
- **log ฝั่ง server บอกว่าตอบถูก**: `[touch] gp-check-1 แตะ animal_xxx (โปรโตเซราท็อปส์ lv5) — ให้ปุ่มโจมตี`
- แต่ฝั่ง test client ได้ `Touched` ที่เป็น **struct ว่างทั้งก้อน** (id ว่าง · name ว่าง · lv 0 · Interactions เป็น null)
  ซึ่ง `Touched.Unpack` ไม่มีทางคืนค่าแบบนั้นได้เลย (มันสร้าง array เสมอ) — แปลว่า handler ถูกเรียกโดยที่ค่าไม่ได้ถูก unpack
- ลบ config ของเกาะทิ้งให้สร้างใหม่จากโค้ดแล้วก็ยังเป็นเหมือนเดิม (ไม่ใช่เรื่องไฟล์ JSON ที่แก้ด้วยมือ)

**ยังไม่ได้ลอง** (ทำต่อจากตรงนี้): เทียบ byte ของ packet `Touched` ระหว่างสองโหมด ·
ดูว่าชื่อเซิร์ฟภาษาไทย (`--island` ตั้ง `serverName` เป็นชื่อเกาะ) ไปโผล่ใน `Welcome`/`knock`
แล้วทำให้ stream เพี้ยนไหม · ลองตั้งชื่อเกาะเป็น ASCII แล้วเทสซ้ำ

**ผลกระทบ:** เฉพาะโหมด `--island` เท่านั้น — beta 1.0 ที่เปิดจริงใช้โหมดเกาะเดียวจึงไม่โดน

## 4. งานที่เหลือของระบบเกาะ

1. แก้บั๊กข้อ 3
2. patch client ให้เดินทางจากในเกมได้ (ข้อ 2)
3. ให้เมนู `เทสเกม.bat` เปิด/ปิดหลายเกาะพร้อมกันได้
4. เดินทางแล้วเก็บของในกล่องข้ามเกาะ (ตอนนี้ของในกล่องอยู่กับเกาะ) — ถ้าจะทำต้องมี "คลังกลาง"
