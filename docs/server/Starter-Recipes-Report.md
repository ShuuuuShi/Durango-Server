# รายงาน: สูตรคราฟ/แบบก่อสร้างที่ปลดล็อกให้ผู้เล่นตั้งแต่แรก

**วันที่:** 24 ส.ค. 2026 (แก้เพิ่ม 25 ส.ค. 2026 — ดูหัวข้อ "รอบ 2" ท้ายไฟล์)
**สั่งงานโดย:** เจ้าของโปรเจกต์ — "นายคิดว่าไอเทมไหนที่จำเป็นต้องมีสำหรับการเล่นแบบสร้างบ้าน ปลูกผัก
ล่าสัตว์ ควรมีไอเทมไหนบ้าง เขียนรายงานมา แล้วให้แสดงแค่นั้นก่อน ขาดอะไรเราค่อยคุยกันอีกที"

## สรุปสั้น

ก่อนหน้านี้ปลดล็อกให้ครบทุกสูตร (720 สูตร + 570 แบบก่อสร้าง = ทุกอย่างที่เกมรองรับ) เพื่อให้เหมือนโหมด
ออฟไลน์ — แต่พอเข้าเมนูคราฟจริงแล้วรกมาก เพราะมีชุดคอสตูมหลายเทียร์ อาหารหรูหลายสิบเมนู และของ
อีเวนต์เก่า (คริสต์มาส/ฮาโลวีน/ปีใหม่) ปนอยู่เต็มไปหมด ทั้งที่ไม่เกี่ยวกับการเล่นจริง

รอบนี้คัดใหม่ตาม 3 แนวเล่นหลักที่เจ้าของบอก (สร้างบ้าน / ปลูกผัก / ล่าสัตว์) บวกกับของพื้นฐานที่ต้อง
มีติดตัวเสมอ (เสื้อผ้ากันหนาว/ร้อน, ถุงเก็บของ) ได้ทั้งหมด **457 สูตร** (จาก 720) และ **515 แบบก่อสร้าง**
(จาก 570) — ตัดออกไปคือของที่ไม่เกี่ยวกับ 3 แนวนี้โดยตรง (ชุดคอสตูม, อาหารหรู, ของอีเวนต์)

โค้ดอยู่ที่ `server/ServerCore/StarterCuratedContent.cs`, เสียบใช้งานใน `ServerPlayer.Skills.cs`
(`BuildUnlocked()`) แทนที่ `RecipeData.AllRecipeIds`/`AllBlueprintIds` เดิม — **ยังไม่ได้อัพขึ้นเซิร์ฟ
รอทดสอบในเครื่องก่อนตามกติกาที่ตกลงกันไว้**

## เกณฑ์การคัด

ข้อมูลสูตรทั้งหมดมี 12 หมวดหลัก (`Category` ใน `RecipeMeta.cs`) แบ่งเป็นสองกลุ่ม:

**เอาทั้งหมวด** (เป็นแกนหลักของ 3 แนวเล่นอยู่แล้ว ไม่มีอะไรฟุ่มเฟือยปนอยู่):

| หมวด | จำนวน | เกี่ยวข้องกับ |
|---|---|---|
| `weapon_and_tool` | 132 | **ล่าสัตว์** — ขวาน/ดาบ/หอก/ธนู/โบว์ ครบทุกเทียร์ (หิน→กระดูก→โลหะ) รวมชิ้นส่วนย่อย (ใบมีด/ด้าม/สาย) ที่ต้องคราฟก่อนประกอบ |
| `tool` | 74 | **ปลูกผัก+ล่าสัตว์+สร้างบ้าน** — จอบ (`hoe`), เลื่อย (`saw`), พลั่ว (`shovel`), จอบขุดแร่ (`pickaxe`), ฉมวก (`harpoon`), ชุดซ่อม (`repair_kit`) |
| `material_process` | 85 | **ทุกแนว** — แปรรูปวัตถุดิบพื้นฐาน (ไม้กระดาน, เหล็ก, ผ้า, ฟอกหนัง, ปุ๋ย) ที่สูตรอื่นทุกอันต้องพึ่ง |
| `modular_attach` | 64 | **สร้างบ้าน** โดยตรง — ผนัง/หลังคา/พื้น/ประตู/หน้าต่าง ทุกวัสดุ (ไม้/หิน/โลหะ/หนัง) |

**เอาบางหมวดย่อย** (หมวดใหญ่มีทั้งของจำเป็นและของฟุ่มเฟือยปนกัน คัดเฉพาะที่เข้าเกณฑ์):

| หมวด → หมวดย่อยที่เอา | จำนวน | เหตุผล |
|---|---|---|
| `cook` → `cook_fire`, `cook_water`, `cook_preserve`, `cook_ingredient` | 59/152 | เตรียม/ถนอมอาหารจากของล่าสัตว์-ปลูกผัก (ต้ม/ย่าง/ตากแห้ง/หมักเกลือ) — **ตัด** `cook_special`(48 เมนูหรู), `cook_medicine`(24), `cook_yeast_fermentation`(9), `cook_oil`(7), `cook_bake`(5) เพราะเป็นอาหารซับซ้อนหลายวัตถุดิบ ไม่ใช่ของจำเป็นพื้นฐาน |
| `clothing` → `clothes_novice`, `shoes`, `gloves`, `bag` | 43/157 | เสื้อผ้า/รองเท้า/ถุงมือกันหนาว-กันร้อนพื้นฐาน + กระเป๋าเก็บของ (จำเป็นต่อการออกไปล่าสัตว์/ทำสวนกลางแจ้ง) — **ตัด** `clothes_hunter`/`explorer`/`settler`(64, ชุดคอสตูมหลายเทียร์), `reform`(22, แต่งทรงเสื้อ), `accessary`/`part`/`hat`(28, ของประดับ) |

**ตัดทิ้งทั้งหมวด**: `clothing_season2`, `tool_season2`, `process_season2`, `cook_season2`,
`recipe_book` (ของอีเวนต์คริสต์มาส/ฮาโลวีน/ภูเขาไฟ), `system` (6 สูตรระบบภายใน ไม่ใช่ของผู้เล่นคราฟเอง)

รวม **457 สูตร** — ดูรายชื่อเต็มใน `server/ServerCore/StarterCuratedContent.cs`

### แบบก่อสร้าง (Blueprints — ของวางประดับ/เฟอร์นิเจอร์/สิ่งปลูกสร้างสำเร็จรูป)

ลิสต์นี้ไม่มีข้อมูลหมวดหมู่แบบสูตรคราฟ (เป็นแค่รายชื่อ prototype id เฉยๆ) เลยคัดด้วยการตัดชื่อที่มี
คำบ่งชี้อีเวนต์/ฤดูกาลออก (`halloween`, `xmas`, `christmas`, `2018_summer`, `army`, `compi`, ฯลฯ)
ที่เหลือ 515/570 เป็นเฟอร์นิเจอร์/สิ่งปลูกสร้างพื้นฐานเกือบทั้งหมด (เตียง, โต๊ะ, ตู้, กรง, เตาไฟ,
สะพาน, กระท่อมไม้) ซึ่งตรงกับแนว "สร้างบ้าน" อยู่แล้วโดยธรรมชาติ ไม่ต้องคัดเข้มเท่าสูตรคราฟ

## MinLevel ไม่ต้องคัดซ้ำ

สูตรแต่ละอันมี `MinLevel` กำกับอยู่แล้ว (470 สูตรเปิดตั้งแต่ Lv.1, ที่เหลือไล่ระดับถึง Lv.55) — ระบบ
เดิมซ่อนสูตรเกินเลเวลผู้เล่นอัตโนมัติอยู่แล้วทั้งฝั่ง client และ server ดังนั้นลิสต์นี้ไม่ตัดตามเลเวลซ้ำอีกชั้น
ตัวละคร Lv.1 จะเห็นแค่สูตรเทียร์ต้นๆ ของ 457 อันนี้ก่อน แล้วเห็นเพิ่มเองตามเลเวลที่อัพขึ้น (เหมือนที่ควรจะ
เป็นอยู่แล้ว)

## รอบ 2 (25 ส.ค. 2026) — จำกัดเลเวล 30 + ซ่อนของที่ยังคราฟไม่ได้จริง + กันของอีเวนต์ที่ server จริงจัง

เจ้าของสั่งเพิ่ม 3 อย่าง หลังลองรอบแรกแล้ว:

> "เราจำกัดแค่ เลเวล 30 ของอันไหนที่ใช้วัตถุดิบสูงกว่าเลเวลตัวละคร ให้ซ่อนเลย เช่น มีดเลเวล 15 ต้องใช้
> วัตถุดิบเลเวล15 แต่ตัวละครพึ่งเลเวล 10 ยังไม่ต้องแสดง หรือ ต้องใช้โต๊ะคราฟ ให้แสดงแค่ตอนเปิดโต๊ะคราฟ
> เท่านั้น ไอเทมสิ่งก่อสร้าง event ให้ใช้ได้แค่ admin เท่านั้น"

### 1) จำกัดสูตรที่ MinLevel ≤ 30

ลิสต์สูตร (recipes) จาก 457 → **354 อัน** — ตัดเทียร์สูง (35/40/45/50/55) ออก 103 อัน สูตรระดับนี้ยังเห็น
อัตโนมัติเองเมื่อตัวละครเลเวลถึง (ผ่านระบบ `RecipeUnlockData.Collect` ตอนเรียนสกิลสายนั้นๆ) ไม่ได้ปิดถาวร
แค่ไม่ได้ "ปลดล็อกให้ตั้งแต่แรก" อีกต่อไป — แบบก่อสร้าง (blueprints) ไม่มีข้อมูล MinLevel ให้คัดตามแกนนี้
(เกมผูก unlock ของสิ่งก่อสร้างกับสกิล ไม่ใช่เลเวลโดยตรง) เลยคงไว้ 515 อันเท่าเดิม

**เรื่อง "มีดเลเวล 15 ต้องใช้วัตถุดิบเลเวล 15 แต่ตัวละครเลเวล 10 ไม่ควรเห็น"** — จริงๆ นี่คือพฤติกรรมที่
ระบบเดิมทำอยู่แล้ว (`RecipeSelectorGroup.IsValidCategoryItem()` เทียบ `PlayerBehavior.LocalPlayer.Level`
กับ `MinLevel` ของสูตรอยู่ก่อนแล้ว ตัวละคร Lv.10 จะไม่เห็นสูตร MinLevel 15 อัตโนมัติ) ไม่ได้แก้เพิ่มตรงนี้
เพราะเป็นของเดิมที่ถูกอยู่แล้ว — ที่แก้จริงคือจำกัด "ลิสต์ปลดล็อกตั้งต้น" ให้ไม่เกิน Lv.30 ตามข้อ 1

### 2) ซ่อนสูตรที่ต้องใช้โต๊ะคราฟ จนกว่าจะยืนอยู่ที่โต๊ะนั้นจริง

`client/Durango.UI/RecipeListWidget.cs` (`EnumerateItems()`) — เดิมรอบแรกลบเงื่อนไขซ่อน
`CraftBlocker.Materials` ออกไปแล้ว (ของขาดวัตถุดิบยังโชว์แบบจางๆ) แต่ `CraftBlocker.Workbench`
(ของครบวัตถุดิบ แต่ไม่ได้ยืนที่โต๊ะ/เตาที่ต้องใช้) ไม่เคยถูกซ่อนมาก่อนเลย — เพิ่มเงื่อนไข:

```csharp
if (!IsFavorites && blocker == CraftBlocker.Workbench)
{
    continue;   // ต้องใช้โต๊ะที่ไม่ได้ยืนอยู่ตอนนี้ — ซ่อนไว้ก่อน โผล่เองตอนเดินไปยืนที่โต๊ะที่ใช่
}
```

ผลคือ: สูตรที่ต้องใช้ "กองไฟ" จะไม่โผล่เลยจนกว่าจะยืนอยู่หน้ากองไฟ, สูตรที่ต้องใช้ "โต๊ะทำอาวุธ" ก็เช่นกัน
— เมนูคราฟจะสั้นลงมากตอนไม่ได้อยู่ที่โต๊ะไหนเลย (ส่วนใหญ่จะเหลือแต่สูตรมือเปล่า)

### 3) ของอีเวนต์ให้ admin เท่านั้น — แก้ที่ server จริง ไม่ใช่แค่ซ่อนที่ client

ตรวจโค้ดฝั่ง server แล้วพบว่า **client-side hide ไม่พอ** — `HandleCraft` (คราฟ),
`HandleOccupyArtifactSite` (จองที่สร้างสิ่งปลูกสร้าง), `HandlePlaceCapsulatedArtifact` (วางของจากแคปซูล)
ไม่เคยเช็คเลยว่าสูตร/แบบก่อสร้างที่ client ส่งมาอยู่ใน "unlocked set" ไหม — เช็คแค่ level/วัตถุดิบ/โต๊ะ/
เครื่องมือ/ตำแหน่งเท่านั้น แปลว่าแก้ client หรือยัด packet ตรงๆ ก็ยังคราฟ/วางของอีเวนต์ได้อยู่ดี แม้จะไม่ถูก
ปลดล็อกให้เห็นในเมนูก็ตาม

เพิ่มการเช็คจริงที่ server:
- **ใหม่** `RecipeData.IsEventRecipeCategory(category)` — เช็คหมวด `clothing_season2`/`tool_season2`/
  `process_season2`/`cook_season2`/`recipe_book`
- **ใหม่** `RecipeData.IsEventBlueprint(blueprintId)` — เช็คชื่อ blueprint ด้วยแพทเทิร์นเดียวกับตอนคัด
  `StarterCuratedContent.Blueprints` (halloween/xmas/christmas/army/compi/season2 ฯลฯ)
- `ServerPlayer.Crafting.cs` (`HandleCraft`) — ปฏิเสธถ้าหมวดสูตรเป็นของอีเวนต์และ `!IsAdmin`
- `ServerPlayer.Building.cs` (`HandleOccupyArtifactSite`, `HandlePlaceCapsulatedArtifact`) — ปฏิเสธถ้า
  blueprint เป็นของอีเวนต์และ `!IsAdmin`

ผู้เล่นทั่วไปคราฟ/วางของอีเวนต์ไม่ได้แล้วจริงๆ ไม่ว่าจะพยายามยังไงก็ตาม แอดมิน (ผูก IP/entity_id ผ่าน
`--admin` ตอนเปิดเซิร์ฟ) ยังใช้ได้ปกติ
