## 🍳 ระบบทำอาหารเปิดแล้ว — 152 สูตร

ไม่ใช่แค่ "กดแล้วได้ของ" แต่บังคับเงื่อนไขจริงเหมือนเกมต้นฉบับ

- 🔥 **ต้องมีไฟ** — ยืนกลางทุ่งแล้วสั่งย่างไม่ได้ ต้องยืนที่กองไฟ/เตา
- 🍳 **ต้องมีเครื่องมือถูกชนิด** — ต้มต้องมีหม้อ · ย่างต้องมีเตาย่างหรือไม้เสียบ
- 📈 **เตาไล่ระดับ** — กองไฟ → กองไฟใหญ่ → เตาดิน → ครัว ยิ่งดีทำสูตรยากได้มากขึ้น
- 🥩 **ของดิบให้พลังน้อยกว่าและทำให้ล้า** — นี่คือเหตุผลที่ต้องเอาเนื้อไปย่างก่อนกิน

ตัวเลขจริงที่วัดได้:

| เมนู | สตามินาที่ได้ |
|---|---|
| เนื้อดิบ | +19 |
| เนื้อย่าง | **+32** |
| เนื้อต้ม | **+40** |

- ⏳ **มีเวลาย่อย** — กินรัวทั้งกระเป๋ารวดเดียวไม่ได้แล้ว
- 🥣 **ผลลัพธ์เปลี่ยนตามวัตถุดิบ** — สูตรน้ำซุปอันเดียว ใส่เนื้อได้น้ำซุปเนื้อ ใส่ผักได้น้ำซุปผัก
- 🍲 ข้อมูลโภชนาการเป็นของจริงจากตัวเกม **352 ชนิด** (เมื่อก่อนกินอะไรก็ได้ +30 เท่ากันหมด)

## 🐛 บั๊กใหญ่ที่เจอระหว่างทาง (อันนี้สำคัญ)

> **สูตรคราฟต์ 587 จาก 720 อัน กดไม่ได้มาตลอด — โดยไม่มีใครรู้**

ตัวเกมใช้ "ป้ายชนิดของโต๊ะ" ที่เซิร์ฟส่งไปเป็นตัวตัดสินว่าสูตรไหนทำที่โต๊ะนี้ได้
แต่เซิร์ฟเรา **ไม่เคยส่งป้ายนั้นไปเลย** → ตัวเกมหาโต๊ะที่ "ผ่าน" ไม่เจอสักตัว
→ ทุกสูตรที่ต้องใช้โต๊ะหายไปจากเมนูเงียบ ๆ ไม่มี error ไม่มีข้อความ

แก้จุดเดียวปลดล็อกทั้งหมด ไม่ใช่แค่สายทำอาหาร ✅

**และอีกอันที่เจอตอนเล่นจริง** — เมนูคราฟต์เคยซ่อนสูตรที่ "ทำไม่ได้ตอนนี้" ทิ้ง
พอเพิ่มเงื่อนไขโต๊ะ/เครื่องมือเข้าไป สูตรเลยหายไปทั้งกระดานเวลาไม่ได้ยืนที่โต๊ะพอดี
→ ตอนนี้ **โชว์แบบสีจางพร้อมบอกว่าขาดอะไร** จะได้รู้ว่าต้องไปทำอะไรก่อน 💡

## 📊 สกิลอัพเองแล้ว

เกมนี้มีสกิล 2 ชั้น แต่เราทำไปแค่ชั้นเดียว — ที่เหลือคือ **ความชำนาญที่ขึ้นเองจากการทำงาน**
เมื่อก่อนเก็บของทั้งวันหน้าสกิลก็ยังเป็น 0 อยู่ดี 😅

ตอนนี้ขึ้นเองจริงตามตารางของเกมต้นฉบับ:

| ทำอะไร | ชำนาญอะไร |
|---|---|
| เก็บของ | การเก็บของ |
| แล่ซาก | การชำแหละ |
| ล่าสัตว์ | การต่อสู้ระยะประชิด |
| โดนตีแล้วรอด | การป้องกัน |
| กินอาหาร | การเอาชีวิตรอด |
| สร้างของ | การก่อสร้าง |
| คราฟต์ | แยกตามชนิด — ทำอาหาร / ทำอาวุธ / ทำเสื้อผ้า / แปรรูป |

ขึ้นเลเวลแล้วมีข้อความเด้งบอก และเซฟข้ามวันแน่นอน 💾

## 🩹 แก้เพิ่มอีกชุด

- 🩸 **หลอดเลือด/สตามินาขึ้น 999/999 ตอนเพิ่งเข้าเกม** แล้วต้องเดินไปเก็บของก่อนถึงจะตรง
  → ตอนนี้ค่าถูกต้องตั้งแต่วินาทีแรกที่เข้าเกม
- 🔥 **กองไฟที่วางจากกระเป๋าใช้เป็นโต๊ะคราฟต์ไม่ได้** (เซิร์ฟนับว่าเป็นแค่ "พื้นที่จองไว้") → แก้แล้ว
- ⏱️ **คราฟต์อะไรก็ 2 วินาที เสียสตามินาเท่ากันหมด** → ใช้ค่าจริงของแต่ละสูตรแล้ว
- 🥄 **สูตรที่ควรได้ 2 ชิ้นเคยได้ชิ้นเดียว** → ได้ครบตามข้อมูลเกม
- 🔒 **เลเวลขั้นต่ำของสูตรไม่เคยมีผล** → มีผลจริงแล้ว

## 🚧 ยังไม่มี / ยังติดอยู่

อยากให้เห็นภาพตรงกัน ไม่อยากขายฝัน 🙏

- 🈳 **ชื่อไอเทมยังเป็นภาษาเกาหลี** — ข้อมูลในตัวเกมเป็นเกาหลีล้วน ยังไม่ได้แปล
- 🍚 **ยังไม่มีหลอด "ความอิ่ม"** — อาหารเติมพลัง/เลือดได้แล้ว แต่ระบบความหิวยังไม่เปิด
  (ข้อมูลสกัดไว้พร้อมแล้ว รอเปิดรอบหน้า)

- 🌾 เพาะปลูก · ปศุสัตว์ · สิทธิ์ที่ดิน · เควส — **คิวถัดไป ยังไม่ได้เริ่ม**
- 🐾 เพ็ท / ปาร์ตี้ / แคลน / ตลาด / แชทส่วนตัว — ยังไม่ถึงคิว
