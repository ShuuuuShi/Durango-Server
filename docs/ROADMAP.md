# Roadmap — จาก beta ถึงเปิดจริง

เป้าหมายปลายทางอยู่ที่ [GOAL.md](GOAL.md) · ไฟล์นี้คือ**ลำดับและเกณฑ์**ว่าจะไปถึงยังไง

**สรุปสั้น: beta 4 รอบ แล้วเปิดจริง** — แต่ละรอบมีเงื่อนไข "ผ่าน" ชัดเจน ไม่ผ่านไม่ขึ้นรอบถัดไป

| รอบ | ชื่อ | คนเล่น | เวลา | เปิดอะไรใหม่ |
|---|---|---:|---|---|
| **B1** | เกาะเดียวให้ครบวงจร | 1-3 | ~1 สัปดาห์ | ของที่มีอยู่ตอนนี้ทั้งหมด |
| **B2** | เพื่อนกลุ่มเล็ก | 5-10 | ~2 สัปดาห์ | ความทนทานเครื่องมือ · อาหาร/ความหิว |
| **B3** | หลายเกาะ | 10-20 | ~2 สัปดาห์ | เกาะแยกเลเวล + เดินทางในเกม |
| **B4** | ซ้อมเปิดจริง | 20-32 | ~1 สัปดาห์ | ไม่เปิดของใหม่ — เน้นความนิ่ง |
| **เปิดจริง** | 1.0 | 32+ | — | ประกาศสาธารณะ |

## B1 — เกาะเดียวให้ครบวงจร (อยู่ตรงนี้)

**คำถามที่ต้องตอบให้ได้:** "เล่นคนเดียว 2 ชั่วโมงแล้วยังอยากเล่นต่อไหม"

### ต้องเสร็จก่อน
- [x] แตะสัตว์ได้ปุ่มโจมตี · สัตว์สวนกลับไว · แล่ซากได้
- [x] ระบบเลเวล/exp · สกิลมีผลจริง · เครื่องมือบังคับใช้จริง
- [x] `config.json` ปรับสมดุลได้โดยไม่ต้อง build
- [x] สัตว์เกิดเป็นโซน · แก้อาการเดินวาร์ป
- [ ] **เล่นจริง 2 ชั่วโมงรวด** ตามเช็คลิสต์ (ข้อ 4 ในเมนู)
- [ ] ความทนทานเครื่องมือ (ขวานพังได้) — ไม่งั้นคราฟต์ครั้งเดียวใช้ตลอดชีวิต

### เกณฑ์ผ่าน
| # | เกณฑ์ | วิธีวัด |
|---|---|---|
| 1 | `--gp-check` ผ่านครบ | รันจากเมนูข้อ 6 |
| 2 | `--multi-check` ผ่านครบ | เมนูข้อ 7 |
| 3 | บอทฟาร์ม 3 ตัว 30 นาที: exception 0 · tps ≥ 110 · RAM ไม่โตเกิน 20% | เมนูข้อ 9 |
| 4 | **เล่นเอง 2 ชั่วโมง** ไม่มีอาการวาร์ป/ค้างท่า/ของหาย | เช็คลิสต์เมนูข้อ 4 |
| 5 | ไปถึงเลเวล 10 ได้โดยไม่รู้สึกว่าต้องกรindซ้ำ ๆ | จับเวลาจริง |

## B2 — เพื่อนกลุ่มเล็ก (5-10 คน)

**คำถาม:** "เล่นด้วยกันแล้วดีกว่าเล่นคนเดียวไหม"

### เปิดใหม่
- ความทนทานเครื่องมือ + ซ่อมได้
- อาหาร/ความหิว (เหตุผลที่ต้องล่าและทำครัว)
- แชทส่วนตัว (ต้องทำ auth ให้ radiotower ก่อน — M-5)

### เกณฑ์ผ่าน
| # | เกณฑ์ |
|---|---|
| 1 | 5 คนออนพร้อมกัน 2 ชั่วโมง · เซิร์ฟไม่ล่ม · tps ≥ 110 |
| 2 | **ไม่มีของหาย** — ทุกคนออกเกมแล้วเข้าใหม่ ของครบทุกชิ้น |
| 3 | แย่งเก็บของ/แย่งแล่ซากพร้อมกันแล้วของไม่ถูกปั๊ม |
| 4 | มีคนอย่างน้อย 1 คนกลับมาเล่นวันรุ่งขึ้นโดยไม่ต้องชวน |
| 5 | เก็บ feedback ได้อย่างน้อย 10 ข้อ และแก้ข้อที่ซ้ำกัน ≥ 3 คนให้หมด |

### สิ่งที่ต้องเตรียม (ไม่ใช่โค้ด)
- เปิดให้เข้าจากนอกบ้าน (port forward / tunnel) + คู่มือเข้าเซิร์ฟ 1 หน้า
- ที่รับบั๊ก (ห้อง Discord) + แบบฟอร์มสั้น ๆ: ทำอะไรอยู่ / เกิดอะไร / ควรเป็นอะไร
- **สำรองเซฟทุกวัน** (เมนูข้อ 12)

## B3 — หลายเกาะ (10-20 คน)

**คำถาม:** "พอมีเกาะที่สอง คนอยากไปไหม และไปแล้วยังสนุกไหม"

### เปิดใหม่
- เกาะแยกเลเวล 3 เกาะ (lv1-10 / 10-20 / 20-30) + เดินทางในเกม
- สัตว์เลี้ยง (ถ้าทัน) — ขยายรัศมีการเดินทาง

### เกณฑ์ผ่าน
| # | เกณฑ์ |
|---|---|
| 1 | เดินทางข้ามเกาะในเกมได้จริง ของ/เลเวล/สกิลไปด้วยครบ 100% |
| 2 | เปิด 3 เกาะพร้อมกัน 3 ชั่วโมง ไม่มีเกาะไหนล่ม |
| 3 | คนที่เลเวลถึงเลือกไปเกาะ 2 เอง**โดยไม่ต้องบอก** |
| 4 | `--gp-check` ผ่านครบใน**ทุกเกาะ** (ตอนนี้โหมด `--island` ยังตก 2 ข้อ — ต้องแก้ก่อน) |
| 5 | ไม่มีของก๊อประหว่างเกาะ (ทดสอบเฉพาะ: ถือของ → ข้ามเกาะ → ตัดเน็ตกลางทาง) |

## B4 — ซ้อมเปิดจริง (20-32 คน)

**ไม่เปิดของใหม่เลย** — รอบนี้มีไว้พังอย่างเดียว

| # | เกณฑ์ |
|---|---|
| 1 | 20 คนออนพร้อมกัน 3 ชั่วโมง · tps ≥ 100 ตลอด |
| 2 | ทดสอบเซิร์ฟล่มกลางคัน: kill process แล้วเปิดใหม่ — ของหายไม่เกิน 60 วินาทีสุดท้าย |
| 3 | ทดสอบคนสแปม: ยิง packet รัว / เข้าออกรัว ๆ → โดนเตะ เซิร์ฟไม่กระเทือน |
| 4 | เปิดทิ้งไว้ 24 ชั่วโมงไม่มีคนเล่น: RAM นิ่ง · ไฟล์เซฟไม่โต · สัตว์ครบโควตา |
| 5 | คู่มือคนดูแลเซิร์ฟใช้งานได้จริง (ให้คนอื่นลองเปิดเซิร์ฟตามคู่มือ) |
| 6 | มีแผนกู้คืน: เซฟหาย/เซิร์ฟพัง ทำยังไง — **ซ้อมกู้จริง 1 ครั้ง** |

## เปิดจริง 1.0

**เงื่อนไข:** B1-B4 ผ่านหมด · ไม่มีบั๊กระดับ "ของหาย/เซิร์ฟล่ม" ค้างอยู่

| ก่อนเปิด | ตอนเปิด | หลังเปิด |
|---|---|---|
| สำรองเซฟ + ทดสอบกู้คืน | เปิดด้วย `--whitelist` (cheat ปิด) | ดู log วันละครั้ง |
| ตรึงเวอร์ชัน (ไม่แก้โค้ดวันเปิด) | ประกาศ + คู่มือเข้าเซิร์ฟ | สำรองเซฟทุกวัน |
| เตรียมประกาศ + กติกา | เฝ้า 3 ชั่วโมงแรก | รวบรวมบั๊กเป็นรอบ ๆ ไม่แก้สด |

### กติกาหลังเปิดจริง
1. **ไม่แก้โค้ดบนเซิร์ฟที่มีคนเล่น** — แก้บนเครื่องเทส ผ่าน `--gp-check` แล้วค่อยขึ้น
2. **ทุกอัปเดตต้องผ่าน gp-check + multi-check** ไม่มีข้อยกเว้น
3. **สำรองก่อนอัปเดตทุกครั้ง**
4. ปรับสมดุลใช้ `config.json` (ไม่ต้องปิดเซิร์ฟ) — แก้โค้ดเฉพาะตอนเพิ่มระบบ

## ของที่ยังไม่จัดลงรอบ

ฟาร์ม · ตลาด · แคลน · ภารกิจ · เกาะที่ 4+ — เอาไว้หลัง 1.0
**เหตุผล:** เปิดระบบเยอะแต่ไม่นิ่ง แย่กว่าเปิดน้อยแต่เล่นได้จริงทุกอย่าง
