# Durango Claude — เกมนี้จะเป็นอะไร

เอกสารนี้ตอบ 3 คำถาม: **ทำเสร็จแล้วมีระบบอะไรบ้าง · เล่นไปทางไหน · สนุกตรงไหน**
(แผนว่าจะไปถึงตรงนั้นยังไง อยู่ที่ [ROADMAP.md](ROADMAP.md))

---

## 1. ประโยคเดียวที่อธิบายเกมนี้

> **เกาะที่ทุกอย่างต้องทำเอง** — ล่าสัตว์เอาวัสดุ → คราฟต์เครื่องมือ → เครื่องมือเปิดทางให้เก็บของที่ดีกว่า
> → ของที่ดีกว่าพาไปเกาะที่อันตรายกว่า และตลอดทางมีบ้านของคุณกับเพื่อนตั้งอยู่จริงในโลกเดียวกัน

ไม่ใช่เกมเควสต์ ไม่ใช่เกมตีบอส — เป็น**เกมเอาชีวิตรอด/สร้างฐาน**ที่ความคืบหน้าวัดจาก
"เมื่อวานยังตัดไม้ไม่ได้ วันนี้มีขวานเหล็กแล้ว" มากกว่าตัวเลขเลเวล

## 2. ระบบทั้งหมดเมื่อทำเสร็จ

### แกนหลัก — มีแล้ว ✅

| ระบบ | สภาพตอนนี้ |
|---|---|
| เอาชีวิตรอด | เลือด · สตามินา · ความล้า (ล้ามาก = ทำอะไรก็เปลืองขึ้น) |
| เก็บของจากธรรมชาติ | จุดเก็บเป็นของกลางทั้งเซิร์ฟ ใครเก็บก่อนได้ก่อน หมดแล้วหายจริง |
| **เครื่องมือ** | ตัดไม้ต้องมีขวาน · แล่ซากต้องมีมีด · ทุบหิน/แร่ต้องมีอีเต้อ |
| คราฟต์ | ตรวจ tag + วัสดุตามสูตรจริงของเกม (720 สูตร) เอาของผิดมายัดไม่ผ่าน |
| ล่าสัตว์ | 10 ชนิด · นิสัยต่างกัน (หนี / สู้กลับ / ไล่กัดก่อน) · คูลดาวน์กัดค่าจริงจากเกม |
| **แล่ซาก** | เนื้อ/หนัง/กระดูก/เขา/ขนนก — ตัวใหญ่ได้เยอะกว่า |
| เลเวล + exp | ตารางค่าจริงของเกม · ได้ exp จากล่า/เก็บ/แล่/คราฟต์/สร้าง |
| **สกิล** | 275 สกิล 12 หมวด — **มีผลจริง**: เก็บเร็วขึ้น · ดาเมจ · ลดดาเมจ · คราฟต์เร็ว · ประหยัดสตามินา |
| สร้างสิ่งปลูกสร้าง | 40 หลัง/คน · กองไฟใช้เป็นโต๊ะคราฟต์ · กล่องเก็บของ 200 ชิ้น |
| เล่นด้วยกัน | เห็นกันจริง · แชทช่องรวม · ของไม่ถูกปั๊มเวลาแย่งเก็บจุดเดียวกัน |
| ตาย/ฟื้น | ตายแล้วฟื้นที่จุดเกิด **ไม่เสียของ** |
| **ทำอาหาร** | 152 สูตร · ต้องมีไฟที่แรงพอ + เครื่องมือ · **ของดิบให้พลังน้อยกว่าและทำให้ล้า** |

### กำลังทำ 🚧

| ระบบ | เหลืออะไร |
|---|---|
| **เกาะแยกตามเลเวล** | โครงเสร็จ (คนละ terrain/สัตว์/ไฟล์เซฟ · ตัวละครข้ามเกาะพร้อมของ) · เดินทางในเกมเขียนแล้วยังไม่ได้เทส |
| **โซนที่อยู่อาศัย** | สัตว์เกิดและเดินอยู่ในโซนของมัน (ทุ่งหญ้า/ชายป่า/ที่ราบสูง/หุบแร็ปเตอร์) — เพิ่งทำ ต้องเล่นดูจริง |

### จะทำต่อ 📋

| ระบบ | ทำไมถึงสำคัญกับ "ความสนุก" |
|---|---|
| ความทนทานของเครื่องมือ | ขวานพังต้องทำใหม่ = มีเหตุผลให้กลับไปหาวัสดุเรื่อย ๆ |
| ความหิว/ความอิ่ม | อาหารเติมสตามินา/เลือดแล้ว แต่ยังไม่มีหลอด "อิ่ม" (ข้อมูล satiety สกัดไว้แล้ว) |
| สัตว์เลี้ยง (เพ็ท) | เกมต้นฉบับมีข้อมูลครบ — ขี่/ให้ขนของ = ขยายรัศมีการเดินทาง |
| ฟาร์ม/ปลูกพืช | ทางเลือกให้คนไม่ชอบสู้ ได้มีอะไรทำ |
| ตลาด/แลกของ | ให้ของที่หายากมี "ราคา" ระหว่างผู้เล่น |
| ปาร์ตี้/แคลน | ล่าตัวใหญ่ด้วยกัน สร้างหมู่บ้านด้วยกัน |
| แชทส่วนตัว | นัดกันโดยไม่ต้องประกาศทั้งเซิร์ฟ |

> เมนูของระบบที่ยังไม่ได้ทำถูกซ่อนไว้ 24 เมนู — จะเปิดทีละอันตอนที่ระบบพร้อมจริง

## 3. เล่นไปทางไหน — วงจรหลักของเกม

```
        ┌──────────────────────────────────────────────┐
        │                                              ▼
   เก็บวัสดุ ──→ คราฟต์เครื่องมือ ──→ เก็บ/ล่าของที่ดีกว่าเดิม
        ▲                                              │
        │                                              ▼
   สร้างฐาน ←── ของหายาก/พื้นที่ใหม่ ←── ไปเกาะที่อันตรายกว่า
```

**หนึ่งชั่วโมงแรก** เก็บหิน → คราฟต์มีด → ล่ากิ้งก่าแล้วแล่เนื้อ → วางกองไฟ → คราฟต์ขวาน → ตัดไม้ได้
**หนึ่งวันแรก** เลือกสายสกิล (สู้/เก็บของ/ช่างฝีมือ) → บ้านหลังแรก → เริ่มล่าตัวที่สู้กลับ
**หลังจากนั้น** ไปเกาะเลเวลถัดไป — สัตว์แรงขึ้น ของดีขึ้น และของเดิมกลายเป็นของพื้นฐาน

## 4. สนุกตรงไหน — 5 อย่างที่เกมนี้ตั้งใจให้รู้สึก

**1. "เมื่อวานทำไม่ได้ วันนี้ทำได้"**
ความคืบหน้าเป็นรูปธรรม ไม่ใช่แค่ตัวเลข — ต้นไม้ต้นเดิมที่เมื่อวานตัดไม่ได้เพราะไม่มีขวาน
วันนี้ตัดได้แล้ว **นี่คือหัวใจของเกม** และเป็นเหตุผลที่เครื่องมือต้องบังคับจริง ๆ ไม่ใช่ของประดับ

**2. ความกลัวที่มีระดับ**
กิ้งก่าวิ่งหนีเรา · โปรโตเซราท็อปส์สู้กลับ · **แร็ปเตอร์ไล่กัดก่อน**
พอสัตว์อยู่เป็นโซน ผู้เล่นจะจำได้เองว่า "ทางนั้นยังไปไม่ได้" — และวันที่กล้าเดินเข้าไปคือวันที่รู้สึกเก่งขึ้นจริง

**3. โลกที่มีคนอื่นอยู่จริง**
บ้านที่คนอื่นสร้างตั้งอยู่ตรงนั้นจริง · ของในจุดเก็บมีจำกัดและใครมาก่อนได้ก่อน
· ซากสัตว์ที่เพื่อนล่าไว้ช่วยกันแล่ได้ — ไม่ใช่โลกที่ทุกคนเห็นสำเนาของตัวเอง

**4. ตายแล้วไม่หมดตัว**
ตายเสียเวลา ไม่เสียของ — เกมนี้อยากให้กล้าลองสู้กับตัวที่ใหญ่กว่าตัวเอง
ไม่ใช่เกมที่เล่นแบบกลัวจนไม่กล้าออกจากบ้าน

**5. เลือกทางเป็นของตัวเอง**
แต้มสกิลมีจำกัด — จะเป็นนักล่า ช่างฝีมือ หรือนักเก็บของ เลือกได้
และเพราะเล่นด้วยกันในโลกเดียว คนที่เลือกต่างกัน**ต้องพึ่งกัน** (คนตีเก่งได้หนังเยอะ แต่ช่างฝีมือทำเกราะให้ได้ดีกว่า)

## 5. สิ่งที่เกมนี้ **จะไม่** เป็น

- **ไม่มีเควสต์สายหลัก** — โลกไม่บอกว่าให้ไปไหน ผู้เล่นตั้งเป้าเอง (อยากได้ขวานเหล็ก → ต้องหาแร่ → แร่อยู่เกาะถัดไป)
- **ไม่มีร้านขายพลัง** — ของทุกอย่างมาจากการหา/ทำเอง
- **ไม่ใช่ PvP** — เกาะ PvP ของเกมเดิมปิดไว้ ความกดดันมาจากธรรมชาติ ไม่ใช่จากผู้เล่นอื่น
- **ไม่รีบ** — ไม่มีอีเวนต์รายวันบังคับล็อกอิน เข้ามาเล่นเมื่ออยากเล่น ของยังอยู่ครบ

| ระดับ | วัดจาก |
|---|---|
| ขั้นต่ำ | เพื่อน 5-10 คนเข้ามาเล่นด้วยกันได้ 2 ชั่วโมงโดยไม่มีอะไรพัง |
| ที่ตั้งใจ | มีคนกลับมาเล่นวันรุ่งขึ้น**เพราะอยากทำของที่ค้างไว้ให้เสร็จ** |
| ที่หวัง | มีหมู่บ้านที่ผู้เล่นสร้างร่วมกันโดยไม่มีใครสั่ง |
