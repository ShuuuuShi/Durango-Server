# รายการเทส — Durango Claude

เทสมี 2 ชั้น: **อัตโนมัติ** (บอทยิง packet เอง ตรวจว่า server ปฏิเสธ/ยอมถูกไหม)
กับ **เล่นจริง** (นั่งเล่นด้วยตัวเกม ตรวจว่ามันสนุก/ไม่พังในสายตาผู้เล่น)

> อัตโนมัติจับ "server ทำถูกไหม" · เล่นจริงจับ "ผู้เล่นเห็นอะไร"
> **บั๊กที่เจอตอนเล่นจริงทุกตัวที่ผ่านมา อัตโนมัติจับไม่ได้เลย** (ปุ่มไม่เด้ง · สัตว์ค้างท่า · เมนูว่าง)
> ⇒ ผ่านอัตโนมัติครบไม่ได้แปลว่าเปิดได้

---

## A. เทสอัตโนมัติ

รันจากเมนู `เทสเกม.bat` หรือสั่งเองก็ได้ · เมนูจะเปิดเซิร์ฟโหมดเทสให้เองถ้ายังไม่ได้เปิด

| เมนู | คำสั่ง | ตรวจอะไร | ผ่านคือ | ใช้เวลา |
|---|---|---|---|---|
| **6** | `--gp-check` | กันโกง 45 ข้อ — ยิง packet ปลอมทุกทาง (ของไกลเกินเอื้อม · ของคนอื่น · เลเวลปลอม · สกิลปลอม · ทิ้งของที่ไม่มี) | **45/45** | ~3 นาที |
| **20** | `--cook-check` | ระบบทำอาหาร 11 ข้อ (รายละเอียดข้างล่าง) | **11/11** | ~40 วินาที |
| **21** | `--recipe-check` | ข้อมูลสูตร/อาหารทั้งชุด — ไม่ต้องเปิดเซิร์ฟ | `✅ ผ่านทั้งหมด` | ทันที |
| **7** | `--multi-check` | 3 คนออนพร้อมกัน · แย่งเก็บของจุดเดียวกันแล้วของไม่ถูกปั๊ม | **9/9** | ~1 นาที |
| **8** | `--bot ... 5` | บอทฟาร์ม 5 นาที — เก็บของ/คราฟต์วนไปเรื่อย | exception 0 | 5 นาที |
| **9** | โซกเทส | บอท 3 ตัว 30 นาที | tps ≥ 110 · RAM ไม่โตเกิน 20% · exception 0 | 30 นาที |
| — | `--tool-check` | ความทนทานเครื่องมือ (สึก/พัง/ทำไม่สำเร็จต้องไม่สึก) | ผ่านครบ | ~2 นาที |
| — | `--stamina-check` | สตามินาลดจริงตอนทำงานต่อเนื่อง | ผ่านครบ | ~2 นาที |

### `--cook-check` เช็คอะไรบ้าง (11 ข้อ)

| # | ข้อ | ทำไมต้องมี |
|---|---|---|
| 1 | ย่างกลางทุ่ง (ไม่มีกองไฟ) **ไม่ผ่าน** | ยิง packet ตรงต้องทำอาหารโดยไม่มีไฟไม่ได้ |
| 2 | บอกเหตุผลว่าต้องใช้กองไฟ | ผู้เล่นต้องรู้ว่าทำไมกดไม่ได้ ไม่ใช่เงียบ |
| 3 | วางกองไฟจากแคปซูลแล้วใช้เป็นโต๊ะได้ | เคยพังตรงนี้ — วางออกมาเป็น "แค่จองพื้นที่" |
| 4 | ต้มเนื้อโดยไม่มีหม้อ **ไม่ผ่าน** (ตอบ `ToolNeeded`) | เครื่องมือต้องบังคับจริง |
| 5 | ย่างที่กองไฟ **สำเร็จ** | ทางที่ถูกต้องต้องผ่าน ไม่ใช่ปฏิเสธหมด |
| 6 | ได้ของ "สุกแล้ว" ไม่ใช่เนื้อดิบ | ผลลัพธ์ต้องเปลี่ยนสภาพจริง (tag `raw_food` หลุด) |
| 7 | เนื้อดิบถูกใช้ไป 1 ก้อน | วัตถุดิบต้องหักจริง ไม่ใช่ได้ของฟรี |
| 8 | กินเนื้อดิบแล้วได้สตามินา | ระบบอาหารทำงาน |
| 9 | กินติดกันทันที **ไม่ได้** (เวลาย่อย) | กันรัวกินทั้งกระเป๋ารวดเดียว |
| 10 | **ของสุกให้พลังมากกว่าของดิบ** | ถ้าข้อนี้ตก = ไม่มีเหตุผลให้ทำอาหารเลย |
| 11 | ต้มน้ำซุปที่กองไฟธรรมดา **ไม่ผ่าน** | เตาต้องแรงพอ — นี่คือความคืบหน้าของสายทำอาหาร |

### `--recipe-check` เช็คอะไรบ้าง

- มีสูตรไหน **คราฟต์ไม่ได้เลยตลอดกาล** ไหม (ขอ tag โต๊ะที่ไม่มีโต๊ะตัวไหนให้ได้)
- สูตรเริ่มต้นของผู้เล่นใหม่ทุกอันมีจริงในข้อมูลเกมไหม · ต้องมีโต๊ะ/เครื่องมืออะไร
- อาหารแต่ละอย่างให้พลังเท่าไรจริง ๆ หลังคูณสเกลใน config
- **ของสุกให้พลังมากกว่าของดิบทุกชนิดไหม**

⚠️ `⚠` ในรายงานไม่ใช่ข้อผิดพลาด — แปลว่า "สูตรนี้ต้องไปสร้างโต๊ะที่ดีกว่าก่อน" ซึ่งคือความคืบหน้าของเกม

## B. เช็คลิสต์เล่นจริง — ระบบทำอาหาร (~15 นาที)

**เตรียม:** เมนูข้อ **1** (เปิดเซิร์ฟ + เกม + ต่อให้) → เข้าเกมแล้วเปิดเมนูข้อ **5** (กล่องเครื่องมือ)
→ ข้อ **5 เสกของ** → ข้อ **5 ชุดทำอาหาร** (ได้เนื้อ 3 · กิ่งไม้ 2 · น้ำ 2 · หม้อ · เตาย่าง · กองไฟ + กองไฟใหญ่)

### B1 — ไฟบังคับจริงไหม
```
[ ] เปิดกระเป๋า วางกองไฟลงพื้น แล้วรอจนขึ้นเป็นกองไฟจริง (ไม่ใช่โครงร่างโปร่ง ๆ)
[ ] เดินออกห่างกองไฟไปไกล ๆ แล้วเปิดเมนูคราฟต์ → สูตร "꼬치구이 / ย่างไม้เสียบ" ต้อง กดไม่ได้ (เทา)
[ ] เดินกลับมายืนติดกองไฟ เปิดเมนูคราฟต์อีกที → สูตรเดิม กดได้แล้ว
```
> ถ้ายืนติดกองไฟแล้วยังเทาอยู่ = `AppearArtifact.Tags` ไม่ถูกส่ง (บั๊กเดิมที่เพิ่งแก้) — ดู `WorkbenchTagData.cs`

### B2 — เครื่องมือบังคับจริงไหม
```
[ ] เอากิ่งไม้ออกจากกระเป๋า (ทิ้ง/ใส่กล่อง) แล้วลองย่าง → ต้องขึ้นหน้าต่าง "ต้องใช้เครื่องมือ"
[ ] เอากิ่งไม้กลับมา แล้วย่างใหม่ → ผ่าน
[ ] เอาหม้อออก แล้วลองสูตร "ต้ม" → ต้องขึ้นหน้าต่างเครื่องมือเหมือนกัน
```

### B3 — ย่างแล้วได้อะไร
```
[ ] ย่างเนื้อ 1 ก้อน → หลอดเวลาเดินจริง (ไม่ใช่เสร็จทันที) แล้วได้ของเข้ากระเป๋า
[ ] ของที่ได้ ชื่อเปลี่ยน (มีคำว่าย่าง/꼬치구이 นำหน้า) และ ไอคอนเปลี่ยน
[ ] กดดูรายละเอียดของชิ้นนั้น → คุณสมบัติ "ดิบ (날 것)" หายไปแล้ว
[ ] เนื้อดิบในกระเป๋าลดลง 1 ก้อน (ไม่ใช่ได้ของเพิ่มฟรี)
[ ] สตามินาลดลงตอนย่าง (ไม่ใช่ทำฟรี)
```

### B4 — กินแล้วต่างกันจริงไหม ★ ข้อสำคัญที่สุด
```
[ ] ใช้กล่องเครื่องมือทำให้สตามินาหมด (หรือวิ่ง/เก็บของจนหมด) แล้วดูตัวเลขหลอด
[ ] กินเนื้อดิบ 1 ก้อน → จดว่าสตามินาขึ้นเท่าไร (ควรราว +19)
[ ] กินซ้ำทันที → ต้อง กินไม่ได้ + ขึ้นข้อความ "เพิ่งกินไป รออีกสักครู่"
[ ] รอ ~5 วินาที ทำสตามินาหมดอีกที แล้วกินเนื้อที่ย่างแล้ว → ต้องขึ้นมากกว่าเดิมชัดเจน (ราว +32)
[ ] ท่าที่ตัวละครเล่นตอนกินของเหลว (น้ำ/ซุป) เป็นท่าดื่ม ไม่ใช่ท่าเคี้ยว
```
> ดิบ ≈ สุก = ระบบไม่มีความหมาย · ปรับได้ที่ `data/config.json` → `Food` (มีผลใน 5 วินาที ไม่ต้อง build)

### B5 — เตาไล่ระดับจริงไหม
```
[ ] ยืนที่ "กองไฟ" ธรรมดา → สูตรน้ำซุป (육수 내기) ต้อง กดไม่ได้
[ ] วาง "กองไฟใหญ่" แล้วยืนที่กองไฟใหญ่ → สูตรน้ำซุป กดได้
[ ] ทำน้ำซุปด้วยเนื้อ 3 ก้อน + น้ำ 1 → ได้ "น้ำซุปเนื้อ (고기 육수)" 2 ถ้วย
[ ] ทำใหม่โดยใส่ผัก/ผลไม้แทนเนื้อ → ได้ซุปคนละอย่าง (ชื่อ/ไอคอนต่างกัน)
```
> ข้อสุดท้ายพิสูจน์ว่า "ผลลัพธ์เปลี่ยนตามวัตถุดิบ" ทำงาน

### B6 — ของสุกอยู่ข้ามเซสชันไหม
```
[ ] เก็บเนื้อย่างไว้ในกระเป๋า → ออกเกม → เข้าใหม่
[ ] เนื้อย่างยังเป็นเนื้อย่าง (ไม่กลับไปเป็นเนื้อดิบ) และกินแล้วยังได้พลังเท่าเดิม
```
> ถ้ากลับเป็นดิบ = `ItemSave.Processed` ไม่ถูกเซฟ

### B7 — ไม่พังของเดิม
```
[ ] เมนูคราฟต์ยังเปิดได้ปกติ ไม่ค้าง ไม่มีสูตรที่ขึ้นชื่อว่างเปล่า
[ ] คราฟต์ของที่ไม่ใช่อาหาร (มีดหิน/ขวาน) ยังทำได้เหมือนเดิม
[ ] หน้าต่างเซิร์ฟไม่มี [error] / exception ตลอดที่เล่น
```

## C. เช็คลิสต์เล่นจริง — ของเดิม 30 นาที

(เกณฑ์ข้อ 3 ของ beta 1.0 — เมนูข้อ **4** ก็โชว์รายการนี้)

```
[ ] คลิกที่สัตว์แล้ว "ปุ่มโจมตีสีแดง" เด้งขึ้นมา
[ ] ตีสัตว์แล้วมันสวนกลับ/วิ่งหนีภายใน ~1 วินาที (ไม่ยืนนิ่ง)
[ ] สัตว์ไม่วาร์ป ไม่ค้างท่า ตายแล้วนอนนิ่ง (ไม่ล้มแล้วลุกวน)
[ ] ฆ่าแล้วซาก "เรืองแสง" ขอบวิบวับ
[ ] แตะซาก (ต้องออกจากโหมดต่อสู้ก่อน) มีเมนู เนื้อ/หนัง/กระดูก
[ ] แล่แล้วของเข้ากระเป๋าจริง และแล่จนหมดตัวแล้วซากหายไป
[ ] ตายแล้วกดฟื้น จอเด้งกลับจุดเกิดจริง
[ ] ออกจากโหมดต่อสู้ได้ (ปุ่มถอย/Esc)
[ ] กระเป๋าเต็มแล้วกด "ทิ้ง" ได้
[ ] เก็บของธรรมชาติ + คราฟต์ + สร้างกองไฟได้
[ ] นั่งพักที่กองไฟแล้วความล้าลดจริง
[ ] ตลอด 30 นาที หน้าต่างเซิร์ฟไม่มี [error] / exception
```

## E. ตกข้อไหน ดูตรงไหน

| อาการ | สงสัยตรงนี้ก่อน |
|---|---|
| สูตรขึ้นแต่กดไม่ได้ ทั้งที่ยืนถูกที่ | `AppearArtifact.Tags` / `WorkbenchTagData.cs` — client ตัดสินจาก tag ที่ server ส่ง |
| ทำอาหารได้แต่ของไม่เปลี่ยนสภาพ | `ItemProcessing.ProcessedTags` · สูตรนั้น type 0 หรือ 1 (ดู `--recipe-check`) |
| กินแล้วไม่ได้พลัง / กินไม่ได้ | `FoodData` ไม่มี prototype นั้น — ของบางอย่างเกมไม่ได้ตั้งใจให้กิน |
| ดิบกับสุกได้พลังพอ ๆ กัน | `data/config.json` → `Food.RawFoodEnergyScale` |
| เมนูขึ้นสูตรของระบบที่ปิดอยู่ | `BuildUnlocked` ใน `ServerPlayer.Skills.cs` — ต้องกรองที่ฝั่ง server ด้วย |
| ค่าอะไรแสดงเป็น "เต็ม/สูงผิดปกติ" | server ไม่ได้ส่งค่านั้นมา → client ใช้ค่าเดิมของตัวเอง (ดู CHANGELOG 17 ส.ค.) |

## F. สั่งเองไม่ผ่านเมนู

```bash
# เซิร์ฟโหมดเทส (ต้องมี --enable-cheat ไม่งั้นเทสตกยกแผง)
cd "C:\Users\thana\Desktop\Durango Claude\server"
dotnet run -- --enable-cheat --admin gm

# ตรวจข้อมูลอย่างเดียว ไม่ต้องเปิดเซิร์ฟ
dotnet run -- --recipe-check

# ฝั่งบอท
cd "C:\Users\thana\Desktop\Durango Claude\test-client"
dotnet run --no-build -- --gp-check
dotnet run --no-build -- --cook-check
dotnet run --no-build -- --multi-check
dotnet run --no-build -- --tool-check
dotnet run --no-build -- --stamina-check
```

cheat ที่ใช้บ่อยตอนเทสด้วยมือ (ผ่านกล่องเครื่องมือ เมนูข้อ 5 → `control <ชื่อ> ...`):

| คำสั่ง | ทำอะไร |
|---|---|
| `give cook` | ชุดทำอาหารครบเซ็ต |
| `give <prototype>` | เสกไอเทมอะไรก็ได้ที่มีในเกม (`meat` · `pot_02` · `stone`) |
| `heal` / `kill` / `spawn` | เติมเลือด / ฆ่าตัวเอง / เรียกสัตว์ |
| `status` | ตำแหน่ง/เลือด/จำนวนของ |

ในคอนโซลเซิร์ฟ (เมนูข้อ 10 = บอทคอนโซล) ใช้ได้อีกชุด: `clearbag` · `rest` · `tired` · `survival` · `tools`
