# Roadmap — ตามสเปกเกมเพลย์เปิดตัว (Beta 1.0.0)

สถานะ: อนุมัติโดยเจ้าของ 2026-09-02  
แกนหลัก: `docs/Plan/Durango-Beta-1.0.0.md` (+ `1.0.0 beta.txt`)  
อ้างอิงเสถียรภาพเดิม: `docs/testing/BETA-1.0-PLAN.md` (ใช้เป็นฐาน S1 ไม่ใช่ทิศเหนือ)

## หลักการ

1. ยึดสเปกเกมเพลย์ตอนเปิดตัวเกาหลี (ม.ค. 2018) เป็นเส้นฐาน
2. ไล่ระบบที่ยังขาดตามลำดับด้านล่าง
3. งานเสถียร/กันโกงที่มีแล้วไม่ทิ้ง แต่ไม่ดึงลำดับฟีเจอร์
4. ของที่ไม่ได้อยู่ในสเปกเปิดตัว = อย่าใส่ในรอบนี้

## เฟสงาน

### S0 — ล็อกสเปก
- [x] เลือกแกน = สเปกเปิดตัว
- [x] ล็อกรายการเข้า/ตัด + เลื่อนเผ่า
- [x] อัปเดต brief/handoff ให้ชี้มาที่ไฟล์นี้

### S1 — เสถียรแกนเล่น
เป้าหมาย: ฐานที่มีอยู่ไม่พังตอนเติมระบบ  
**กฎเทส (เจ้าของล็อก 2026-09-02):** เทสหลักต้องใช้ตัวเกมจริง + มอดของโปรเจกต์ และบังคับตัวละครด้วยมอด (MemoryBot) เท่านั้น เพื่อประสบการณ์เหมือนผู้เล่นจริง — gp-check / multi-check ใช้ประกอบฝั่งเซิร์ฟ/กันโกงได้ แต่ไม่ใช่การยืนยัน client และไม่ใช่ทางแก้ปัญหา client

อ้างอิงเกณฑ์เดิมใน `BETA-1.0-PLAN.md` ข้อ 4 ตามความเหมาะสม
- [ ] เทสเกมจริงผ่าน MemoryBot ครอบคลุมลูปพื้นฐานโดยไม่โกงข้ามเกต
- [ ] gp-check / multi-check ยังผ่านหลังงานใหญ่แต่ละก้อน (ประกอบเซิร์ฟ)
- [ ] cheat ปิดเป็นค่าเริ่มต้นตอนโหมดเปิดจริง
- [ ] เซฟ/whitelist/อัตราติ๊กเสถียรพอสำหรับเติมฟีเจอร์

### S2 — ลูปชั่วโมงแรก
- [ ] รถไฟ / ทิวโทเรียล / วาร์ปเข้าโลก (หรือเทียบเท่าที่เล่นได้)
- [ ] อาชีพต้นทาง 8 แบบ (ดันสกิลต้น ไม่ล็อกสาย)
- [ ] สามหลอดชีวิต / พลังงาน / ความล้า ใช้งานจริงตามสเปก
- [ ] เก็บของ → คราฟต์พื้นฐาน → พัก/ไฟ ตามลูปเปิดตัว

### S3 — ที่ดิน + T-stone พื้นฐาน
- [x] ประกาศที่ดินบนเกาะเสถียร (เทสผ่าน 39/39 + คงอยู่หลังรีสตาร์ท 5/5 — `--estate-check`)
- [x] ขยายที่ดิน / สิทธิ์พื้นฐาน (เพดาน 64 ช่อง · บังคับสิทธิ์ Occupy จริง — ดู docs/server/Estate.md)
- [ ] ค่าดูแลหมดอายุแล้วคืนที่ (ตอนนี้เก็บวันหมดไว้เฉย ๆ ไม่มี job เก็บกวาด)
- [ ] ค่าดูแล (ปรับเบาได้ถ้าคนน้อย)
- [ ] T-stone สำหรับที่ดิน / เดินทางพื้นฐาน
- [ ] สิ่งปลูกสร้างต้นเกมที่จำเป็น (ที่นอน กองไฟ โต๊ะ ฯลฯ)

### S4 — สกิล 12 สาย + SP
- [ ] โครง 12 สายตรงสเปกเปิดตัว
- [ ] SP จากเลเวลตัว + ปลดโหนดที่จำเป็นต้นเกม
- [ ] เกตสกิลไม่ให้ข้ามด้วย cheat ในโหมดเล่นจริง

### S5 — สู้มี stance + สมดุลโซนต้น
- [ ] โหมดสู้ + เปลี่ยนท่าทาง (stance)
- [ ] สมดุลสัตว์โซนต้นตามสเปก/แผนเกาะเริ่ม
- [ ] ตาย-ฟื้น / ขอช่วย (อย่างน้อยเส้นทางพื้นฐาน)

### S6 — เกาะไม่เสถียร
- [ ] เกาะชั่วคราว ทรัพยากรหนา ล้าเร็ว
- [ ] เข้า-ออก / กลับเกาะเสถียร
- [ ] โลจิสติกส์ของ (ไม่ให้พังตอนรีเซ็ตเกาะ)

### S7 — จับ / ฝึกไดโน
- [ ] เครื่องมือจับ + เงื่อนไขสกิลต้นทาง
- [ ] สัตว์ที่จับได้กินช่องกระเป๋าตามดีไซน์
- [ ] คอกฝึกบนที่ดินเกาะเสถียร
- [ ] ซัมมอน / ช่วยแบกอย่างน้อยระดับต้นเกม

### S8 — องค์กร + เควสต์
- [ ] องค์กรต้นเกม (วิทยุ/สถานี) ตามสเปก
- [ ] เควสต์ให้ XP/ของ + เส้นทางขอสนับสนุนพื้นฐาน
- [ ] ไม่บังคับเผ่าในเฟสนี้

### หลัง S8 (คิวเลื่อน)
- เผ่า / หมู่บ้านร่วม / แชร์ที่ดินเผ่า

## Definition of Done รายเฟส

เฟสถือว่าจบเมื่อ:
1. ระบบในเฟสนั้นเล่นได้ใน client จริง (`dist\DurangoTH-Clean`) โดยไม่โกงข้ามเกต
2. ไม่ทำให้เกณฑ์เสถียรหลักของ S1 regress แบบรู้เห็น
3. handoff สั้นอัปเดตว่าอะไรเข้า/ค้าง/ห้ามแตะ
4. สิ่งนอกสเปกเปิดตัวไม่ถูกเปิดโดยไม่ตั้งใจ

- มะลิ = ประสานตาม Roadmap นี้ · นอกแผนต้องเตือนแล้วพากลับ

- นักทดสอบ = เทส/เกณฑ์
- ช่าง Client = client/mod
- ที่ปรึกษาเกมเพลย์ = ทักท้วงเมื่อหลุดสเปกเปิดตัว

- ห้ามแจกซอร์สโค้ด
