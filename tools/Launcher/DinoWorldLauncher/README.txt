🦋 DinoWorld Launcher
═════════════════════

ตัวเปิดเกม DinoWorld — เข้าเซิร์ฟโดยตรง ไม่ต้องพิมพ์ IP

วิธีติดตั้ง (ทำครั้งเดียว)
─────────────────────────
1. ก๊อปไฟล์ DinoWorldLauncher.exe ไปไว้ใน "โฟลเดอร์เกม"
   ⚠️ ต้องวางข้างๆ ไฟล์ DurangoV2.exe (ไฟล์เดียวกัน ไม่ต้องเอาโฟลเดอร์อื่นมา)

   โฟลเดอร์เกมจะหน้าตาประมาณนี้:
   📁 DurangoTH/
      ├─ DurangoV2.exe          ← เกม
      ├─ DinoWorldLauncher.exe  ← ← ← (วางตัวนี้เพิ่ม)
      └─ ...ไฟล์อื่นๆ ของเกม

2. ดับเบิลคลิก DinoWorldLauncher.exe (ใช้ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม)

3. กดปุ่ม ⚙️ ตั้งค่า → ใส่ที่อยู่เซิร์ฟ เช่น 127.0.0.1:8190
   → 💾 บันทึก → ▶ เข้าเกม

ฟีเจอร์
─────────────────────────
• 📰 ประกาศ/อีเวนต์ — อัปเดตข่าวสารจากเซิร์ฟอัตโนมัติ
• 🟢 สถานะเซิร์ฟ — เช็คว่าเซิร์ฟออนไลน์ + จำนวนผู้เล่น
• ▶ เข้าเกม — เปิดเกมแล้วเชื่อมเซิร์ฟทันที ไม่ต้องกรอก IP
• 📦 อัปเดต/🔧 ซ่อมไฟล์ — โหลดแพทช์+ตรวจไฟล์อัตโนมัติ
  (ถ้าอัปเดตไม่สำเร็จด้วยเหตุผลอะไรก็ตาม เกมเวอร์ชันเดิมยังเล่นได้ปกติ)

คำถามที่พบบ่อย
─────────────────────────
Q: เปิดแล้วขึ้น "ไม่พบ DurangoV2.exe"
A: วางผิดที่ — ต้องวางในโฟลเดอร์เดียวกับตัวเกม DurangoV2.exe

Q: สถานะขึ้น 🔴 ออฟไลน์ / เข้าเกมไม่ได้
A: เช็คว่าใส่ IP:Port ถูกไหม (⚙️ ตั้งค่า) และเซิร์ฟเปิดอยู่หรือเปล่า
   (ถ้าอยู่วง LAN ใช้ IP เครื่องที่รันเซิร์ฟ เช่น 192.168.1.x:8190)

Q: ปลอดภัยไหม / กินแรมไหม
A: Launcher ทำงานแค่ตอนเปิด-อัปเดต-กดเข้าเกม แล้วปิดตัวเองเมื่อเกมเปิด
   ไฟล์ exe นี้ไม่ต้องติดตั้ง .NET อะไรทั้งสิ้น

🦋 ขอให้สนุกกับ DinoWorld!
