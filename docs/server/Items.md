# ทิ้งของ / กินของ — `ServerCore/ServerPlayer.Items.cs`

สอง handler ที่ client ยิงมาตั้งแต่แรกแต่ **ฝั่ง server ไม่เคยมีใครรับ** จนถึง beta 1.0

เจอตอนโซกเทสบอทฟาร์ม 30 นาที (15 ส.ค. 2026): bot เก็บของจนเต็ม 50 ช่องภายใน ~2 นาที
แล้วหลังจากนั้นทำอะไรไม่ได้อีกเลย — คนเล่นจริงก็จะตันเหมือนกัน และหนักกว่าเพราะ
คนเพิ่งเข้าเกมยังไม่มีกล่องเก็บของให้ถ่ายของลง

## `DumpItems` (TypeCode 16) — ทิ้งของ

client ส่งมาตอนกด "ทิ้ง" ในกระเป๋า (`InventorySystem.DropItems`)
ถ้ามี `Tile` มาด้วย client จะ **เดินไปที่ tile นั้นก่อน** แล้วค่อยส่ง packet

| ฟิลด์ | ความหมาย | server ใช้ยังไง |
|---|---|---|
| `ItemIds` | รายการที่จะทิ้ง | id ที่ไม่มีจริง **ข้ามเงียบ ๆ** ไม่ทำให้ของอื่นหาย |
| `SourceProp` | ทิ้งของ "ในกล่อง" ไม่ใช่ในกระเป๋า | ต้องผ่าน `CanUseBox()` (M-4: เป็นกล่องของตัวเอง + อยู่ในระยะเอื้อม) |
| `SourcePetEntityId` · `SectionName` · `Floor` | ยังไม่ใช้ | — |

ข้อจำกัด: **50 ชิ้นต่อ 1 packet** (`MaxDumpPerRequest`) — กันยิงลิสต์ยาว ๆ มาให้ไล่ลูป
และตายแล้วทิ้งของไม่ได้

ตอบกลับ: `InventoryUpdated` (ของหายจากกระเป๋า) + `OK` + `Inventory` ชุดใหม่
ถ้าทิ้งจากกล่อง จะ **broadcast** `InventoryUpdated` ของกล่องให้คนที่เปิดกล่องเดียวกันค้างอยู่เห็นด้วย

## `UseItem` (TypeCode 17) — กินของ

client รับได้ทั้ง `StartTimer` และ `OK` เป็นคำตอบว่าสำเร็จ (ดู `InventorySystem.UseItem`)
เราตอบ `ItemUsed` (ให้เล่นท่ากิน) + `OK`

- ของที่กินได้ตัดสินจาก **prototype** ว่ามีคำเหล่านี้ไหม:
  `fruit` `berry` `meat` `fish` `egg` `mushroom` `nut` `seed` `honey` `milk` `food`
- กินแล้ว: สตามินา **+30** · ความล้า **−15** · ไอเทมหายไป 1 ชิ้น
- กินขวาน/เสื้อผ้า = `Abort`

⚠️ **ข้อจำกัดที่ยอมรับไว้สำหรับ beta:** ยังไม่มีข้อมูลโภชนาการจริงของเกม
(ของจริงมีค่าอิ่ม/บัฟ/เวลาหมดอายุต่อไอเทม) ตอนนี้ทุกอย่างที่กินได้ให้ค่าเท่ากันหมด
ถ้าจะทำจริงต้องดึงตารางอาหารจาก `resources.strings.txt` เหมือนที่ทำกับสูตรคราฟต์

## เทส

อยู่ใน `--gp-check` หมวด "ทิ้งของ/กินของ" (6 ข้อ)

| เทส | ผลที่ต้องได้ |
|---|---|
| ทิ้งของที่ไม่มีในกระเป๋า | `Abort` |
| ทิ้งทีเดียว 80 ชิ้น | `Abort` (เกิน 50) |
| ทิ้งของในกล่องคนอื่น | `Abort` (M-4) |
| กินของที่ไม่มีในกระเป๋า | `Abort` |
| กินขวาน | `Abort` |
| ทิ้งของจริง | ของหายจากกระเป๋าจริง |
