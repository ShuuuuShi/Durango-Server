### 1.3 สมดุลตัวเลข (ต้องปรับ — ของเดิมโหดเกินไป)

สูตรปัจจุบัน: เลือดสัตว์ `50 + lv×10` · ดาเมจสัตว์ `3 + lv×0.6` · ผู้เล่นมือเปล่า ~6 · มีอาวุธ ~16 · เลือดผู้เล่น 100

| สถานการณ์ | ตอนนี้ | หลังปรับ |
|---|---|---|
| มือเปล่า vs สัตว์ lv3 (เลือด 80/68) | ตี 14 ครั้ง = 35 วิ · โดนกลับ 43 | ตี 9 ครั้ง = 22 วิ · โดนกลับ 22 |
| มือเปล่า vs ทริเซรา lv10 (150/110) | **ตี 25 ครั้ง = 62 วิ · โดนกลับ 216 ⇒ ตายแน่นอน** | ตี 14 ครั้ง · โดนกลับ 62 ⇒ รอดแบบหวุดหวิด |
| มีขวาน vs ทริเซรา lv10 | ตี 10 ครั้ง · โดนกลับ 90 | ตี 7 ครั้ง · โดนกลับ 43 |

**สูตรใหม่ที่เสนอ:** เลือด `30 + lv×8` · ดาเมจ `2 + lv×0.4` · และแจก **ขวานหินตอนเข้าเกมครั้งแรก**
(ตอนนี้แจกแค่กองไฟ) — ให้ผู้เล่นใหม่ล่าสัตว์เล็กได้ตั้งแต่นาทีแรกโดยไม่ต้องพึ่งดวง

## 4. เกณฑ์ "พร้อมเปิด beta"

1. ✅ `dotnet run -- --gp-check` ผ่าน **ครบทุกข้อ** — 42/42 (เพิ่มเทสรอบ D + ทิ้งของ/กินของ + แตะสัตว์/แล่เนื้อ)
2. บอทฟาร์ม 30 นาทีติดกัน: ไม่มี exception ในเซิร์ฟ · tps ไม่ต่ำกว่า 100 · RAM ไม่โตเกิน 20%
3. เล่นด้วยตัวเกมจริง 30 นาที: ไม่มีสัตว์วาร์ป/ค้างท่า · ตาย-ฟื้นได้ · ออกจากโหมดต่อสู้ได้
4. ✅ ต่อพร้อมกัน 3 client ในเครื่องเดียว: เห็นกันครบ · ไม่มีของก๊อป — `--multi-check` ผ่าน 9/9
   (สามคนรัวเก็บจุดเดียวกัน 15 ครั้งบนของที่มี 3 หน่วย → ได้รวม 3 ชิ้น ที่เหลือถูกปฏิเสธ)
5. เปิดทิ้งไว้ 3 ชั่วโมงโดยไม่มีคนเล่น: ไฟล์เซฟไม่โต · สัตว์ยังครบตามโควตา
